# AI宠物乐园 —— 课堂宠物养成激励系统 需求文档 V2.1（主题后台管理版）

> 用途：交付 AI Agent 直接生成完整项目。面向小学一年级课堂，用「宠物养成升级」激励学习行为。
> 核心机制：**课堂好表现 → 一键投喂 → 宠物升级 → 里程碑全屏进化 → 全班见证**
> **V2.0**：升级为「本地服务端 + 展示前端 + 管理后台」三端架构，宠物/背景/动画/特效全部主题包化，后台一键切换。
> **V2.1 变更记录**（本次补充，用户确认 + 二轮需求评审）：
> 1. ✅ **多班级支持**：多个班各自独立名单/数据/当前主题
> 2. ✅ **BGM 主题化**：每个主题可配自己的背景音乐，音量/静音独立控制
> 3. 🆕 **行为标签 + 成长时间线 + 表扬名单导出**（激励留下数据痕迹，家长会/期末可用）
> 4. 🆕 **食物也主题化**（海洋主题喂"小鱼干"、糖果主题喂"棒棒糖"）
> 5. 🆕 **课堂模式开关**：专注模式（一键静音+关特效）、投喂锁定（防学生自己点）、退出/切班 PIN
> 6. 🆕 **随机惊喜**：投喂小概率暴击双倍经验（大特效），制造课堂尖叫点
> 7. 🆕 **兑换登记**：虚拟币换现实奖励（免作业卡）时登记核销，老师不忘发货
> 8. 🆕 **宠物昵称**：学生可给自己的宠物起名字（所有权感）
> 9. 🆕 **农场卡片排序**：按等级/姓名/**随机洗牌**（每节课洗牌，公平曝光）
> 10. 🆕 **每日自动备份**（保留最近 7 份）+ 主题编辑器**右侧实时预览**
> 存放目录：`AIGame/ai宠物/` · 运行平台：教室电脑本地，局域网多屏，无需外网

------

## 一、项目概述

### 1.1 定位

课堂宠物养成激励系统：老师把学生的好表现即时兑换成宠物成长资源，宠物的升级与进化成为**全班看得见的成就感**。V2 架构下，老师还能通过管理后台**像换皮肤一样更换整套视觉主题**（宠物+背景+BGM+动画特效+配色+语料），支持自建、保存、一键应用。

### 1.2 三端架构总览

```
┌─────────────────────────────────────────────────────┐
│                 教室电脑本地服务端                     │
│   server.py（Python Flask，项目 .venv 一键启动）       │
│   ├─ HTTP API（展示端/管理端唯一数据入口，串行结算）     │
│   ├─ data/classes/各班数据(JSON) + backups/自动备份    │
│   └─ themes/  主题包（每主题一个文件夹）                │
└──────────┬─────────────────────────┬────────────────┘
           │                         │
   ┌───────▼────────┐       ┌────────▼────────┐
   │ 展示前端 /show   │       │ 管理后台 /admin  │
   │ 投屏宠物农场     │       │ 主题工厂/班级/投喂│
   │ +特效+BGM       │       │ 数据/备份        │
   └────────────────┘       └─────────────────┘
   同机双窗口，或局域网手机/平板访问（管理端可设 PIN）
```

- 展示端 2 秒轮询主题版本号：后台**一键换主题 → 前端热切换**，不刷新不重启
- 一切数据经服务端落盘；换电脑 = 拷贝整个项目文件夹

### 1.3 与已有《ClassPet》（通用工具）的关系

ClassPet 是长期班级管理向（含服务端）；本项目聚焦**宠物养成视觉激励 + 主题工厂**，主题包机制为独有能力，可独立使用。

------

## 二、核心激励循环与一年级红线

```
好表现 → 老师投喂(≤3秒,可带行为标签) → 食物飞向宠物+经验(小概率暴击×2!)
      → 升级金光 → 里程碑全屏进化 → 宠物说话 → 学生更想表现
```

**红线（不可违反）**：宠物永不死亡/降级/被剥夺；排行榜只看等级与「本周进步之星」（按增量）；一切操作可撤销；删除学生=先存档。

------

## 三、多班级支持（V2.1）

- **班级列表**：如「一(1)班 / 一(2)班 / 一(3)班」，每班独立：学生名单、宠物数据、当前主题、BGM 配置、分组
- 数据目录：`data/classes/<班级id>/students.json | config.json | oplog.json`
- **主题包全班级共用**（主题是"皮肤库"），但每个班记录自己当前用哪套——一(1)班海洋、一(2)班太空互不影响
- **切换班级**：管理后台下拉一键切；展示端切班需 PIN（防学生乱点）；切换后展示端整体换数据+换主题
- 新建班级向导：输入班名 → 批量粘贴名单（一行一名）→ 选主题 → 开班
- 同一个班当天第二次打开：自动恢复上次班级与状态

## 四、主题工厂（管理后台核心）

### 4.1 主题包结构（老师零代码可编辑）

```
themes/
  海洋乐园/
    theme.json        # 清单：名称/配色/动画/BGM/语料/食物/宠物定义/规则
    bg.png            # 背景图（可选，也可纯渐变）
    bgm.mp3           # 🆕 主题背景音乐（循环，音量随主题）
    pets/duck/egg.png baby.png adult.png final.png ...
    sfx/              # 可选：覆盖内置合成音效
```

**theme.json 字段**（所有可配置项集中于此，界面与文件双向可改）：

  "animations": { "feed": "arc", "upgrade": "jumpGold", "evolve": "whiteFlash", "speed": 1.0 },
  "foods": [
    { "icon": "🦐", "name": "小鱼干", "exp": 5,  "label": "课堂发言" },
    { "icon": "🐟", "name": "大鱼",   "exp": 10, "label": "作业满分" },
    { "icon": "🦀", "name": "大螃蟹", "exp": 20, "label": "乐于助人" }
  ],
  "corpus": ["小鸭子为你骄傲！", "今天也要加油鸭！"],

### 4.3 管理后台功能清单（/admin，四大页）

**A. 主题工厂页（核心）**
- 主题列表：缩略图卡片，当前主题高亮，**「应用」=一键切换**（展示端热加载）
- 新建主题：空白 / **复制现有主题为模板**（推荐）/ 导入主题包 .zip
- 主题编辑器：**左侧表单 + 右侧实时预览（所见即所得）** 🆕
  - 基本信息：主题名、配色（color picker×4）
  - 背景：内置渐变 / 上传图片（自动压缩≤5MB）
  - BGM：上传音乐 / 试听 / 音量滑条（继承 V1 播放/暂停经验：首次交互后自动播放）
  - 宠物形象：每只每形态「内置SVG / 上传图片 / 恢复默认」即时预览
  - 动画：投喂（抛物线/坠落/闪烁）、升级（金光/星星环绕）、进化（白光/粒子/彩虹）、速度倍率滑条
  - 食物：图标(emoji)/名称/经验值/行为标签 四项可编辑
  - 语料：宠物说话文本列表增删改、一键恢复默认
  - 保存 / 另存为 / 删除（不可删当前主题）

**B. 班级管理页**
- 班级列表：新建班级向导（班名→粘贴名单→选主题）、删除（自动先备份）
- 学生管理：增删改、指定宠物系、经验/等级调整、**宠物昵称**设置、按小组分组
- 批量导入名单（一行一名）

**C. 投喂操作页（老师遥控器，手机可访问）**
- 头像墙点选 → 食物盘投喂（可选行为标签）→ 展示端即时动画
- 批量投喂（小组）、长按连投、最近 5 次撤销

**D. 数据管理页**
- 全量备份导出 .zip / 导入恢复
- **每日自动备份**（首次启动时自动打包，保留最近 7 份）🆕
- 兑换登记：星星币商店换现实奖励（免作业卡等）时登记核销，防忘发货 🆕
- 本周表扬名单导出（文本，可发家长群）🆕
- 重置班级（二次确认+自动备份）

## 五、展示前端 /show（课堂投屏主界面）

- 宠物农场：卡片网格（形象/昵称/Lv经验条/心情表情），**排序可切：按等级/按姓名/随机洗牌（每节课洗牌一次，公平曝光）** 🆕
- 聚焦模式：点学生全屏放大（管理端也可遥控聚焦，回答问题时用）
- **BGM 播放控制** 🆕：右下角 🔊/🔇 + 音量条（BGM 与音效分开调），静音状态记住；浏览器策略下首次点击后自动开播；进化时若主题配了 evolveSting 则 BGM 短暂压低播放进化音
- **课堂模式开关** 🆕：专注模式（一键静音+关闭特效，安静授课时段用）、投喂锁定（防学生自己点）、退出/切班需 PIN
- 投喂/升级/进化全屏特效层（风格由主题驱动）；**暴击特效** 🆕：小概率双倍经验 + 超大特效 + 全班"哇"
- 图鉴页：18 形态点亮进度，集齐全班进化=班级成就

## 六、成长数据与时间线（V2.1 新增模块）

## 七、服务端与 API

- 技术栈：Python 3.9 + Flask（项目 `.venv` 就绪）；`启动.bat` 一键起服务并自动打开展示页+管理页
- 存储：
```
data/
  current_class.txt
  classes/
    class_1ban/  students.json  config.json  oplog.json  timeline.json
backups/  auto_20260913.zip ...（保留7份）
themes/   主题包文件夹
```

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | /api/state?class=x | 展示端全量状态（主题版本+学生+当前班级），轮询 |
| GET/POST | /api/classes | 班级列表/新建/切换 |
| GET | /api/themes · POST /api/themes/apply · /save · /upload_asset | 主题管理 |
| GET/POST | /api/students | 名单与数据 CRUD（含昵称） |
| POST | /api/feed | 投喂（学生/食物/数量/行为标签）→ 服务端结算+暴击判定 |
| POST | /api/undo · /api/redeem | 撤销 / 兑换登记 |
| GET | /api/timeline/:student · /api/stats · /api/praise_week | 时间线/统计/表扬名单 |
| GET/POST | /api/backup | 备份导出/导入 |

## 八、边界与异常

1. 服务端未启动打开展示页 → 引导页「请先双击 启动.bat」
2. 主题素材缺失/损坏 → 回退内置 SVG 兜底，不白屏；theme.json 保存时校验+自动 .bak
3. 上传超大图 → 自动压缩+明确报错
4. 多端同时投喂 → 服务端串行结算，日志保证可撤销
5. 端口占用 → 自动换端口并提示
6. **BGM 自动播放被浏览器拦截** → 首次任何点击后自动开播（写在验收项）
7. 每日自动备份失败 → 顶栏提示，不阻塞使用

5. 代码中文注释，结构清晰

## 十、效果推理

1. **主题工厂是老师的上瘾点**：换主题=全新课堂视觉，一学期 4 套主题=4 段新鲜感，等于白得 4 个系统
2. **多班级让工具从"一个班的玩具"变成"任课老师的日常工作台"**——使用频次翻倍，数据资产（行为标签统计）随时间增值
3. 养成循环有效性：即时反馈（3秒）、成长可见（蛋裂纹/进度条）、情感联结（昵称+我的宠物）、稀缺峰值（进化仪式+暴击尖叫点）
4. **行为标签数据是隐性大价值**：期末评语、家长沟通、评优推荐都有据可依——激励系统的副产品变成老师的职业工具
5. 风险对策：绝对等级攀比→进步之星；后进生动无力→宠物"想念你"柔性拉回；BGM 太吵→独立音量+专注模式一键全静
