# AI宠物乐园 · 使用说明

> 课堂宠物养成激励系统（三端：展示端 / 管理后台 / 本地服务端）
> 完整功能设计见同目录《AI宠物乐园需求文档.md》

## 一、每天上课怎么用（三步）

1. 双击 **`启动.bat`** → 自动打开两个网页：**展示端**（投屏给学生看）和 **管理后台**（老师操作）
2. 学生表现好 → 在管理后台「投喂遥控」页 **点头像 → 点食物** → 展示端立刻播放投喂/升级/进化动画
3. 下课关闭黑色窗口即可，数据自动保存

## 二、管理后台四个页面

| 页面 | 能做什么 |
|---|---|
| 🎨 主题工厂 | **一键切换**海洋/太空/森林/糖果 4 套主题；新建主题（可复制现有主题改）；换背景图、换宠物形象（每只 4 形态都能上传图片）、选动画特效、配 BGM、编辑食物和宠物台词；右侧实时预览 |
| 🏫 班级管理 | 多个班各自独立数据；新建班级向导；学生增删改、宠物昵称、手动调经验 |
| 🍖 投喂遥控 | 头像墙点选投喂（可选行为标签）、批量投喂、撤销、投喂锁定 |
| 💾 数据管理 | 备份导出/导入（每天还会自动备份，保留 7 份）、本周统计、一键生成本周表扬名单、管理 PIN |

## 三、数值规则（默认，可在主题里改）

- 投喂获得经验：小食物 +5、中 +10、大 +20；**10% 概率暴击双倍**
- 等级：Lv n → n+1 需要 10×n 经验（越升越慢，拉长期待）
- 形态：累计 30 经验破壳 → 100 成熟体 → 250 进化体（进化有全屏仪式动画）
- 心情：投喂 +10，隔天 -20（**永不死亡、永不降级**，只是一时没精神）

## 四、常见问题

- **展示端显示"服务未启动"**：先双击 `启动.bat`，再刷新页面
- **BGM 没声音**：浏览器需要先点一下页面才会播放（在展示端随便点一次）；主题工厂里可给每个主题上传自己的 BGM
- **投喂没反应**：检查是否开了「投喂锁定」
- **换电脑**：在数据管理页导出备份 zip → 新电脑装好依赖后导入；或直接拷贝整个 `ai宠物` 文件夹
- **误投喂**：投喂遥控页有「撤销上次」
- **首次使用**：先跑一次 `.venv`（若没有）或执行 `..\` 项目根的虚拟环境；最简单方式是直接双击 `启动.bat`，缺组件时按提示装 `flask`

## 五、目录结构（给维护者）

```
ai宠物/
  server.py      服务端（Flask API，全部业务规则）
  show.html      展示端（投屏页面）
  admin.html     管理后台（主题工厂等四页）
  pets.js        16种宠物×4形态 SVG 形象库（两端共用）
  themes/        主题包（每主题一个文件夹，theme.json + 素材）
  data/          班级数据（JSON）+ backups/ 自动备份
  test_api.py    接口回归测试（python test_api.py）
```

主题编辑既可在界面操作，也可直接改 `themes/<主题>/theme.json`（字段规范见需求文档第四节）。
