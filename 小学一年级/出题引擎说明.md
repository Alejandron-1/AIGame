# 出题引擎 · 说明文档

> `出题引擎.js` —— 所有小数学口算游戏共用的智能出题内核。
> 老师三步出题：**选年级 → 选知识点（可综合练习）→ 选难度**，题目自动匹配教材进度。

## 二、哪些游戏在用

| 游戏 | 接入方式 |
|---|---|
| 🏎️ 数学赛车 | 难度三档（简单/中等/困难）自动映射教材进度：一上10以内 / 一下20以内 / 一下100以内 |
| 🏎️ 飞驰人生口算 | 首页完整选择器：年级 + 知识点（综合/单项）+ 难度，改完立即生效 |
| 🤼 数学拔河 | 自带范围选择（规划中接入引擎，暂保留原逻辑） |

## 三、怎么扩展新知识点

打开 `出题引擎.js`：
1. 在 `TOPICS` 里加一个生成器：`g3a_newtopic: { name: '名称', gen(d) { ... return mk(a,'+',b); } }`（d 是难度字符串）
2. 在 `GRADES` 对应年级的 `topics` 数组里登记 `{ id: 'g3a_newtopic', name: '名称' }`
3. 游戏界面自动出现新知识点

题目格式统一为 `{ text: '3+5=?', ans: 8 }`。

## 四、质量保证

引擎做过 **50101 组断言**的自动化采样测试（每个知识点 × 每档难度 × 300 题）：
答案正确性、非负、进位/退位真实发生、不进位/不退位约束、表内乘除范围、余数合法性等全部通过。
修改引擎后可参考本文档表格重跑同类采样验证。
