# 希沃适配与使用指南（立体图形小镇 & 全套游戏通用）

> 先说结论：**这套游戏就是给希沃一体机准备的**——它们是单文件 HTML，在希沃触控一体机的 Windows 系统里用浏览器打开即用，触屏点击/拖拽/3D 旋转都已适配并实测。
> 「适配希沃」要做的只有三件事：拷文件 → 白板课件里挂链接 → 记住两个按键。

---

## 一、认识你的设备（30 秒）

- **希沃触控一体机** = 一台 Windows 电脑 + 大触摸屏（有的还带 Android 白板双系统，**切到 Windows/OPS 系统使用**）。
- **希沃白板 5（EasiNote）** = 跑在这台电脑上的课件软件。你的游戏不在它里面跑，而是**被它"喊出来"**：白板页面放一个按钮，点一下 → 浏览器全屏打开游戏 → 玩完 Alt+Tab 回白板。

---

## 二、部署（一次性，5 分钟）

1. 把**整个 AIGame 文件夹**拷到一体机，如 `D:\AIGame`（保持内部结构，别单拆文件）。
2. 把**默认浏览器**设为 Edge 或 Chrome（设置 → 应用 → 默认应用）。
3. 双击 `AIGame\小学一年级\认识立体图形-图形小镇课件.html` 能打开 → 部署完成。
4. 可选（推荐）：右键课件 → 发送到桌面快捷方式；右键快捷方式 → 属性 → 目标改为：
   `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app="file:///D:/AIGame/小学一年级/认识立体图形-图形小镇课件.html"`
   ——这样打开就是**无边框全屏**，看起来像专门的教学软件。

---

## ⚠️ 先分清：希沃的「网页导入」和「超链接」是两个东西

- **网页导入**（更多→网页导入）：会把网页**解析后嵌进白板页面**——但它只支持豆包、飞象老师、提前三个白名单平台，**自己的 HTML 链接放不进去**，此路不通，不用试。
  - 本地 `file:///...` 文件同样不支持——**你截图里的"暂不支持"就是这个原因**，该窗口请直接关掉。
- **超链接**（选中元素→右键→超链接）：不解析网页，只是"点一下就打开"，**本地文件和任意网址都能挂**——挂游戏用这个。

## 三、在希沃白板 5 的课件里挂游戏（备课，3 分钟/个）

1. 打开希沃白板 5 → 打开你的课件 → 翻到要玩游戏的页面。
2. **插入 → 图片**，选 `AIGame\小学一年级\图形小镇-公开课工具包\按钮页\按钮-game1.png`（共 4 张游戏按钮 + 1 张完整课件，也可自己写个大字按钮）。
3. **选中图片 → 右键 → 超链接**，两种填法任选：
   - 「超链接」入口在哪：选中后**点右键**的菜单里；或**右侧属性面板**；或顶部**"更多"（…）**——认准名字是"超链接"，不是"网页导入"。
   - **挂本地文件（推荐，离线最稳）**：链接类型选"本地文件"，直接选中
     `D:\AIGame\小学一年级\认识立体图形-图形小镇课件.html`
   - **挂网址（需教室联网，已部署到国内托管时用）**：类型选"网页"，填
     `https://你的用户名.gitee.io/AIGame/小学一年级/认识立体图形-图形小镇课件.html#game1`
   - 锚点直达：地址末尾加 `#game1`（变图形）/ `#game2`（我说你猜）/ `#game3`（连线）/ `#cover`（从头）
   锚点对照：`#game1` 变图形 · `#game2` 我说你猜 · `#game3` 分一分比赛 · `#cover` 从头开始。
4. **授课模式**下点这张图 → 系统问用什么打开 → 选 Edge 并勾选"始终" → 游戏打开直达该环节。
5. 玩完 **Alt + Tab** 切回白板继续讲课。

> 其他游戏（数学赛车、口算 PK 等 19 个）同理：链接到对应 html 文件即可，全部在 `小学一年级` 文件夹里。

## 四、触屏操作（已全部适配并实测）

| 操作 | 怎么做 |
|---|---|
| 变身 / 出名牌 / 选谜语 | 手指**点** |
| 分一分拖物品进框 | 手指**按住拖**到底下的图形上松手（拖错自动弹回） |
| 3D 图形旋转 | 手指在 3D 窗口里**拖** |
| 翻页 | 白板右侧 ‹ › 按钮 / 方向键 / 翻页笔 PgDn |
| 全屏 | 点右上 ⛶ 或按 **F** |

已做的触屏加固：禁双指缩放、长按不弹系统菜单、拖拽不选中文字、音效在首次触摸后自动开启。

## ⚡ 最简单兜底

一时找不到"超链接"入口？在希沃一体机**桌面放课件快捷方式**，上课直接双击打开游戏（浏览器全屏），讲其他内容时 Alt+Tab 回白板——完全绕开白板的链接功能。

## 五、常见问题

| 现象 | 解决 |
|---|---|
| 点了没反应 | 白板处于**批注/书写模式**——批注层挡住了点击，退出批注即可 |
| 没声音 | 先摸一下屏幕任意处（浏览器规则：首次交互后才出声） |
| 点链接没打开/被拦 | 检查路径盘符；允许 Edge 运行；或直接双击课件 HTML |
| 画面变小/有边框 | 按 **F** 全屏；浏览器缩放按 **Ctrl+0** 复位 |
| 分辨率不同 | 已实测 1920×1080 与 4:3 1024×768 均无溢出，一般无需调整 |
| 想联网用最新版 | 浏览器打开 `https://alejandron-1.github.io/AIGame/小学一年级/认识立体图形-图形小镇课件.html`（GitHub Pages，推送后自动同步） |

## 六、分辨率与触控实测记录（2026-10-06）

- 1920×1080（主流希沃大屏）：15 页全扫描零溢出 ✔
- 1024×768（4:3 老屏）：全扫描零溢出 ✔
- 触摸事件（pointerType=touch）：分一分拖拽判定 ✔、3D 旋转 ✔、音效开启 ✔
- 已禁：双指缩放 / 长按菜单 / 文本选中 ✔

## 更新（实测+搜索结论）：希沃的两种入口，别再用「网页导入」

- **网页导入**：只能解析豆包/飞象老师/提前三个白名单平台，本地 HTML 和自建网址都会提示"暂不支持"——**此功能与本项目无关，直接关掉**。
- **超链接**：不受白名单限制，本地文件/网址都能挂——挂游戏只有这一条路。

## 新增：一键启动器（推荐）

`一键启动/` 文件夹里有 **11 个双击即玩的启动器**（完整课件/第1关/四个3D特征页/玩一玩/我说你猜/分一分/数一数/儿歌）：
- 双击 = Edge **无边框全屏**打开对应环节，观感如独立软件；
- 拷到其他电脑后路径若变化，**双击 `重新生成启动器.ps1`**（右键→使用 PowerShell 运行）自动按新位置重建；
- 希沃白板课件里：按钮图片 → 右键超链接 → 本地文件 → 选启动器 `.lnk`（或直接选课件 HTML）。
