## 一、工具包文件夹地图

```
图形小镇-公开课工具包/
├─ 认识立体图形-图形小镇课件.html 的「源头」都在这：

├─ 展开动画管线/          「渲染素材」的生产线：three.js 渲染页 + 逐帧截图脚本
├─ 一键启动/              Edge 应用模式 .lnk ×11 + 重新生成启动器.ps1
├─ 按钮页/                PPT 用整屏按钮图 ×5 + 按钮页.html
├─ 游戏入口.pptx          保底方案 A 的入口 PPT
```

**成品课件不在本文件夹**：`构建单文件.py` 输出到 `../../认识立体图形-图形小镇课件.html`（小学一年级目录下）。
这个路径是硬约束——一键启动的 .lnk、按钮页超链接、PPT 里的链接、GitHub Pages 地址全都指向它，**别移动、别改名**。

## 二、每类素材怎么重新生成

### 1. 形状 PNG / 展开动画 GIF / 希沃小视频 MP4（展开动画管线）

生产线在 `展开动画管线/`，三种渲染页靠 URL 参数出不同内容：

| 渲染页 | 参数 | 产物 |
|---|---|---|
| `render_image.html` | `?shape=cube\|cuboid\|cylinder\|ball` | 静态形状图 960×540（渲染素材/正方体.png 等 4 张） |
| `render_solid.html` | `?frame=N&shape=cube\|cuboid` | 立体逐步展开动画帧（30fps） |
| `render_net.html` | `?frame=N` | 正方体展开图折叠动画帧（30fps） |

重跑步骤（改完渲染页后）：

```bash
# ① 起本地静态服务（capture 脚本走 http://127.0.0.1:8643）
cd 展开动画管线 && python -m http.server 8643

# ② 逐帧截图：参数 = [时间预算秒] [总帧数] [渲染页路径]，默认 520秒/354帧/render_net.html
python capture_frames.py 520 354 render_net.html%26shape=cube   # 注意 & 要写成 %26

# ③ 帧序列 → GIF（PIL 方案，无需 ffmpeg；正方体展开.gif 即此法，约2MB）
python -c "import glob; from PIL import Image
fs = sorted(glob.glob('frames/frame_*.png'))
ims = [Image.open(f).convert('P', palette=Image.ADAPTIVE) for f in fs]
ims[0].save('out.gif', save_all=True, append_images=ims[1:], duration=33, loop=0)"

# ③' 帧序列 → MP4（希沃小视频用，插希沃白板课件更流畅）
ffmpeg -framerate 30 -i frames/frame_%04d.png -pix_fmt yuv420p 正方体展开-希沃小视频.mp4
```

- 截图原理：Edge headless `--virtual-time-budget` 逐帧确定性渲染，每帧独立临时配置目录 + 失败重试（详见 `capture_frames.py` 头注释）。
- `?frame=N` 是关键：动画是**时间的纯函数**（无随机、无真实时钟），同一帧号永远渲染同一画面，所以可以乱序补拍。
- 长方体 GIF = 同一管线 `shape=cuboid` 再跑一遍。

### 2. 单文件课件（素材改动后必须重跑）

```bash
cd 图形小镇-公开课工具包
python 构建单文件.py        # 读课件模板.html + 素材库/*.png → 覆盖 ../认识立体图形-图形小镇课件.html
```

流程：换 `素材库/` 里的图（保持文件名）→ 改模板 → 跑构建 → 浏览器强刷成品课件。
模板用 `ASSET:英文名` 占位，构建脚本会校验缺图并报错退出。

### 3. 一键启动器（课件路径/锚点变化时）

```powershell
cd 一键启动
powershell -ExecutionPolicy Bypass -File 重新生成启动器.ps1
```

脚本自动定位 Edge → 按 `编号-名称` 清单重建 11 个 .lnk，锚点 `#game1`~`#game4` 对应四个游戏。

### 4. 独立 3D 演示页（演示页/）

`正方体展开演示.html`、`长方体相对面演示.html` 各自配同目录 `three.min.js`，双击即用、无需服务。
改这两个页面时直接编辑即可；要加新演示，把 `three.min.js` 一起复制过去就能保持自包含。

### 5. 魔法师导入视频（立体王国2，不在本工具包）

开场动画/魔法师配音视频的生产线在 `../../../视频/立体王国2/`，见其 `使用说明.md`。
配音用 edge-tts；ffmpeg 用 `视频/ffmpeg.exe`（立体王国2 的脚本按 `../ffmpeg.exe` 相对引用，**别挪走它**）。

## 三、改了素材之后的发布检查单

- [ ] `python 构建单文件.py` 重跑，成品课件浏览器强刷验证
- [ ] 渲染素材有更新 → GIF/MP4/PNG 新旧版本对一遍（渲染页改过就重截）
- [ ] 要上网 → 按根目录 `更新部署新页面步骤.md` 推 GitHub Pages（Pages 缓存 1~5 分钟）
- [ ] 公开课拷机 → 拷**整个 AIGame 文件夹**（保持相对位置），按 `PPT整合说明.md` 检查清单过一遍
