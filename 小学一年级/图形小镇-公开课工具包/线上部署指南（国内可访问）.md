# 线上部署指南（国内可访问版）

> 为什么需要：`github.io`（GitHub Pages）在国内校园网/希沃设备上经常打不开，挂在线上的游戏要用**国内平台**。
> 游戏本身是单文件 HTML，任意静态托管都能跑，不需要服务器和数据库。

---

## 方案一：Gitee（码云）Pages —— 推荐，最贴近你现在的用法

**免费、国内直连、教室网络和希沃设备都能打开。**

1. 注册 [gitee.com](https://gitee.com)（手机号即可），完成**实名认证**（开 Pages 的前提）。
2. 新建仓库，名字如 `AIGame`，**公开**，不要勾选"初始化 README"。
3. 把本地项目推上去（在 AIGame 文件夹里执行，用户名换成你的）：
   ```
   git remote add gitee https://gitee.com/你的用户名/AIGame.git
   git push -u gitee main
   ```
4. 开启 Pages：仓库页 → **服务 → Gitee Pages → 启动**（默认分支 main，目录 /）。
5. 得到线上地址（发给谁都能开）：
   ```
   https://你的用户名.gitee.io/AIGame/小学一年级/认识立体图形-图形小镇课件.html#game1
   ```
6. **注意**：Gitee Pages 每次 push 后要手动到 Pages 页面点一下"更新"才生效（免费版规则）。

## 方案二：腾讯云 EdgeOne Pages —— 自动部署，不用每次手动更新

1. 注册腾讯云（微信扫码），实名后进入 [EdgeOne Pages 控制台](https://console.cloud.tencent.com/edgeone/pages)。
2. **连接 GitHub 仓库** AIGame（授权后选仓库，构建命令留空，输出目录填 `/`）。
3. 部署完成得到 `https://xxx.edgeone.app` —— **push 到 GitHub 后自动更新**，国内访问快。
4. 游戏地址 = 该域名 + `/小学一年级/认识立体图形-图形小镇课件.html#game1`。

> 两个方案选一个即可。Gitee 简单稳妥但要手动点更新；EdgeOne 自动但要多走一步云控制台授权。

## 拿到线上地址后，各处把链接换掉

| 用在哪 | 原来 | 改成 |
|---|---|---|
| 希沃白板5 超链接 | `file:///D:/...`（离线也能用，可保留） | 线上地址 + `#game1`（需教室联网） |
| PPT 按钮页超链接 | 同上 | 同上 |
| Web Viewer 加载项 | github.io 地址 | 线上地址 |

锚点不变：`#cover` 封面 · `#game1` 变图形 · `#game2` 我说你猜 · `#game3` 分一分连线 · `#game4` 已删除（数一数在其后）。

## 双保险建议（公开课）

- **主**：希沃一体机本地文件夹离线打开（不依赖网络，最稳）；
- **备**：线上地址（Gitee/EdgeOne），设备换教室时不用拷文件。

两者同时挂：白板页上放两个按钮，"本地打开"与"在线打开"。
