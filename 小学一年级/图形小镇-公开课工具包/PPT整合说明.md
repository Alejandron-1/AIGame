# 立体图形小镇 · PPT 整合说明（公开课当天照着做）

> 本工具包把《认识立体图形-图形小镇课件.html》（16 页整课课件，含 4 个互动游戏）接入你的 PPT，两条路线都给你备好了。
> 上课电脑建议：**提前一天**按下面步骤装好、试放一遍。

---

## 方案 A：游戏入口.pptx（按钮跳转，不联网、不装插件，保底方案）

**包内文件**：`游戏入口.pptx`（5 页，每页整屏一张按钮图，放映时点击即跳转对应游戏）

1. 把 `图形小镇-公开课工具包` 文件夹整个拷到上课电脑，**保持它与 `小学一年级` 文件夹的相对位置不变**（本仓库的目录结构直接拷整个 AIGame 文件夹最省事）；
2. 放映 `游戏入口.pptx`，点按钮页 → 自动在浏览器打开课件并直达对应环节；
3. 看完游戏按 **Alt+Tab** 切回 PPT。

**进阶（更无缝）**：把课件链接改成 Edge 应用模式（无地址栏、像原生软件）：
在按钮页图片上右键 → 超链接 → 编辑，地址改为：
```
../认识立体图形-图形小镇课件.html#game1
```
（`#game1`~`#game4` 分别对应四个游戏；`#cover` 回封面）

**把按钮插到你自己的 38 页 PPT 里**：`按钮页/` 文件夹里有 5 张 1920×1080 成品图（完整课件 + 4 个游戏），在 PPT 对应教学节点插入图片 → 右键图片 → 链接 → 填上面的地址即可。

---

## 方案 B：Web Viewer 加载项（游戏直接长在放映页里，需联网）

**原理**：官方 Web Viewer 插件在幻灯片内嵌网页。限制是只收 **HTTPS 地址**（本地文件不行）——你的 GitHub Pages 站点已实测无 iframe 限制，可嵌入。

1. 上课电脑联网，PowerPoint → **插入 → 获取加载项 → 搜索 "Web Viewer" → 添加**（需登录微软账号，提前装好）；
2. 在需要游戏的那一页插入 Web Viewer，地址填（按要放的游戏改末尾锚点）：
```
https://alejandron-1.github.io/AIGame/小学一年级/认识立体图形-图形小镇课件.html#game3
```
3. 放映时游戏就在幻灯片里跑，翻页即走，**零窗口切换**。

**注意事项**：
- 中文路径已自动 URL 编码，直接粘贴整条即可；
- 游戏更新后 GitHub Pages 有 1~5 分钟缓存，公开课前先放映一遍刷新；
- 教室网络不稳 → 立刻切方案 A（这就是准备两条路线的原因）。

## 方案 C（已实现）：整课 HTML 课件，全程不开 PPT

`认识立体图形-图形小镇课件.html` 本身就是 16 页翻页课件（封面→情境导入→分一分→实物变图形→图形名片→长方体/正方体/比一比/圆柱/球→我说你猜→分一分比赛→数一数→小镇落成颁奖→儿歌→作业），**方向键 / 空格 / 翻页笔 PgDn·PgUp 翻页，F 全屏**。想全程只用一个文件，放映它就够了。
