一键启动 · 使用说明
====================

【独立游戏文件】（14 个 .html，双击 = 默认浏览器全屏打开该环节，自动隐藏课件壳层）
  情境导入 / 第1关-认识小伙伴 / 图形名片 / 认识长方体3D / 认识正方体3D /
  长方体正方体比一比 / 认识圆柱3D / 认识球3D / 玩一玩说一说 / 猜谜语 /
  按形状分一分连线 / 数一数 / 儿歌齐读 / 课后小任务

【.lnk 启动器】双击 = Edge 无边框全屏（观感如独立软件，推荐上课用）

【完整课件】想按整节课流程连着玩，双击桌面 AIGame 里的
  认识立体图形-图形小镇课件.html（方向键/翻页笔翻页）

⚠ 换电脑注意：
  1. three.min.js 必须和这些 .html 放同一文件夹（3D 特征页需要，已包含）
  2. .lnk 里记录的是本机路径——拷到别的电脑后，右键"重新生成启动器.ps1"
     → 使用 PowerShell 运行，自动按新位置重建

在希沃白板课件里挂游戏：按钮图片 → 右键超链接 → 本地文件 → 选某个 .html 或 .lnk
