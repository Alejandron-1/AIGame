# 课本 PPT 简单视频化工作流

> 适用对象：一年级上册数学课本 PPT，以及后续同类型课件。
>
> 目标：**保留课本插图和原意，让画面中的元素适度动起来，配上短台词，快速得到可课堂播放的小视频。** 不追求复杂动画、逐层精修或完整课件重构。
>
> 参考案例：`课本PPT素材/一上七彩课堂/1我上学啦/0.1 可爱的校园.pptx` 及同目录五个参考视频。

## 一、先固定制作原则

1. **以“镜头”为单位，不以“整份 PPT”为单位。** 一个镜头只完成一个观察重点，默认约 5 秒。
2. **一幅关键帧 + 一个主动作 + 一句台词。** 背景动、人物动、镜头大幅运动不要同时堆叠。
3. **先选适合视频化的页，不将 24 页全部做成视频。** 情境图、对话图、导入页优先；练习、答案、总结页通常保留在 PPT 中。
4. **数学准确性优先于“动起来”。** 涉及数量、数字、算式、图形属性时，AI 不得增删物体、改数字或改文字；控制不住就改用静态图轻推近/局部高亮，不强行生成。
5. **默认交付独立短片。** 只有确需连续播放时才合并，不额外添加片头、片尾、转场和背景音乐。
6. **原 PPT 永远不改、不覆盖。** 所有中间文件和成片进入单独的视频化目录。

## 二、标准流程总览

```text
PPT 解析与选页
    ↓
导出/拼接关键帧图片
    ↓
填写镜头表（动作、台词、约束）
    ↓
图生视频（首帧参考，默认约 5 秒）
    ↓
画面、数学内容、配音三项验收
    ↓
按统一规则命名并归档
    ↓
（可选）拼接为课时合集
```

每一步都有明确交接物；上一步未验收，不进入批量生成。

## 第 1 步：解析 PPT，建立页面清单

### 输入
- 一份课本 PPT，例如 `0.1 可爱的校园.pptx`。
- 教师本课想突出的内容（若没有额外要求，按课本页面顺序选择）。

### 操作
1. 记录课件编号、课题、总页数、页面比例。
2. 逐页提取或浏览：页码、标题、正文、插图、对话、练习与总结。
3. 将页面分为五类：

| 页面类型 | 默认处理 | 原因 |
|---|---|---|
| 情境大图、课本跨页插图 | 优先视频化 | 有人物、环境和天然台词 |
| 导入、过渡、总结情境页 | 可选 | 适合一句旁白或轻微环境运动 |
| 数数、比多少、位置关系页 | 谨慎视频化 | AI 容易改变数量和相对位置 |
| 数字、算式、答案、方法总结页 | 原则上不做 AI 动效 | 必须保持文字与符号准确 |
| 课外练习、课时练、空白页 | 跳过 | 不属于低投入视频化的重点 |

4. 标记候选页的“观察重点”，一页只保留一个。例如“观察小兔”“观察跳房子”“认识圆与方”。
5. 对候选页先做 1～3 个试片，确认风格后再批量处理。

### 产出
- `页面清单.md`：页码、页面类型、是否制作、观察重点、风险备注。
- 一份候选镜头页码列表。

### 参考案例事实
- `0.1 可爱的校园.pptx` 共 24 页，PPT 页面为 16:9。
- 五个样片没有覆盖全部页面，而是围绕第 3～4 页所用的校园跨页插图制作。
- 原始插图在 PPT 媒体中分为左右两张竖图，另有人物图；样片使用的是合成后的 4:3 校园全景，而非直接播放 16:9 PPT。

## 第 2 步：准备视频首帧（关键帧图片）

### 输入
- 第 1 步确定的候选页。
- 原 PPT 中的图片、文本框与页面布局。

### 操作
1. **首选整页导出。** 将候选页导出为 PNG，建议长边不低于 1920 像素；不要从聊天截图或视频截图反向取素材。
2. **跨页插图先拼接再导出。** 按课本原始左右关系拼成完整场景，保持人物大小、地平线、色彩和比例一致，不随意重排物体。
3. 清理与镜头无关的 PPT 导航、页码、装饰按钮，但**不得擦掉教学对象或改掉数量**。
4. 图片四周预留少量安全空间，避免人物、对话气泡紧贴边缘。
5. 输出比例服从内容：跨页图可为 4:3，普通课件页可为 16:9。不要为了统一比例而拉伸、裁掉教学对象。
6. 无需为了 AI 图生视频逐个拆出所有元素。只有需要单独控制人物且平台支持局部控制时，才额外抠图；否则整幅图作为首帧即可。

### 产出
- 每个候选镜头一张 `S页码_内容.png`，例如 `S04_校园全景.png`。
- 在页面清单中登记关键帧文件名和画面比例。

### 通过标准
- 与原课本相比，教学对象数量、位置和文字无误。
- 画面清晰，无拉伸，无多余裁切。
- 首帧本身就能看懂本镜头要讲什么。

## 第 3 步：设计单镜头动效与台词

### 输入
- 已验收的关键帧图片。
- 该页的观察重点和课本原对话。

### 操作
为每个镜头填写一行镜头表：

| 字段 | 填写规则 |
|---|---|
| 镜头 ID | `PPT编号_S页码_序号`，如 `0.1_S04_02` |
| 来源 | PPT 文件名、页码、关键帧文件名 |
| 教学目的 | 学生看完要观察或理解的一点 |
| 主动作 | 只写一个，如“小熊抬手指向小兔” |
| 辅助动作 | 可写一个轻微环境动作，如“小鸟轻扇翅膀” |
| 镜头 | 默认固定；需要强调时可缓慢推近或拉远 |
| 台词 | 一句短句，优先沿用课本原话 |
| 限制条件 | 不改数量、不增人物、不改字、不换场景等 |
| 时长 | 默认约 5 秒，以台词自然说完为准 |

### 动效选择规则
- **人物对话：** 说话者轻微转头、抬手、点头或口型变化，其他人保持基本稳定。
- **观察与数数：** 角色指向目标即可；不要让目标物体乱跑、复制或消失。
- **环境导入：** 小鸟轻动、花草轻摆、太阳轻微变化；主体构图不动。
- **形状观察：** 可轻微推近目标，再拉回全景；不要旋转变形物体。
- **思考：** 人物停顿、托腮或轻微皱眉；不需要夸张表演。
- 默认不做快速运镜、场景切换、人物穿行和多人同时说话。

### 台词规则
- 5 秒镜头优先 8～20 个汉字，以自然语速能说完为准。
- 一句只表达一个意思；使用一年级学生能理解的口语。
- 数字按要朗读的形式写，如“二班”“两只”，避免合成读音歧义。
- 保留课本中的量词、比较关系和结论，不随意增加新知识。
- 提问后若需要学生回答，应另留停顿或延长片段，不把答案紧接着说完。
- 不让 AI 自动生成或改写台词；提示词中用引号锁定逐字内容。

### 产出
- `镜头表.md`：一行一个镜头，生成时直接照表执行。
- 每个镜头的动作提示词和确定台词。

## 第 4 步：编写图生视频提示词

### 输入
- 关键帧图片。
- 镜头表中的主动作、辅助动作、镜头、台词与限制条件。

### 通用提示词模板

```text
以输入图片为唯一首帧和视觉依据，保持原图的儿童课本插画风、构图、人物造型、色彩、物体数量和所有教学文字不变。
【主动作】只让【指定角色/元素】做【一个简单动作】。
【辅助动作，可删】【另一元素】仅做轻微、自然的循环动作，其余元素保持稳定。
【镜头】镜头固定，不切换场景；或按镜头表写“缓慢推近/拉远”。
【台词，可删】【角色】用清楚、亲切、适合一年级学生的中文说：“【逐字台词】”。
不要新增人物或物体，不要改变物体数量、位置和大小关系，不要改写文字与数字，不要出现多余肢体、闪烁、变形或突然换景。
```

> 提示词只描述需要发生的变化。越长的形容词和越多的动作，不代表效果越好。

### 按参考样片反推的写法示例（不是原始提示词）

**例 1：指向并提问**
```text
保持校园全景和所有小动物数量不变。左侧拿写字板的小熊轻轻抬手指向两只小兔，动作自然，其他角色基本不动，镜头固定。小熊亲切地说：“数一数，有几只小兔？”不要增加小兔，不要改变画面文字。
```

**例 2：近景拉回并观察形状**
```text
从皮球和教室门附近的近景缓慢拉远到校园全景，抱球的小熊保持自然，其他元素稳定。小熊说：“球是圆圆的，门是长长的、方方的。”保持皮球和门的形状，不改变班级门牌与对话文字，不切换场景。
```

### 产出
- 可粘贴到图生视频平台的完整提示词。
- 与镜头 ID 对应的生成任务。

## 第 5 步：生成视频与配音

### 输入
- 关键帧图片、完整提示词、确定台词。

### 操作
1. 使用**图生视频/首帧参考**模式，不使用纯文生视频，避免重画课本内容。
2. 默认设置：约 5 秒、24fps（若平台可选）、比例跟随关键帧、每个任务只生成一个动作。
3. 若平台支持同步配音，直接将锁定台词放入该镜头；参考样片采用的就是带音轨的短片。
4. 若平台不支持或台词经常读错，则改用备用路线：先生成无对白画面，再用固定的中文童声/亲切女声合成台词，最后将音轨与画面对齐。不要每集更换声音。
5. 同一镜头最多先看 1～2 个候选。动作明显错误就缩短提示词或更换主动作，不连续盲目抽卡。
6. 保留原始下载文件到草稿区；通过验收后再复制或重命名到成片区。

### 产出
- `草稿/镜头ID_v01.mp4`。
- 若使用外部配音：`音频/镜头ID.wav`。
- 在镜头表中登记生成日期、所用平台、版本和结果。

### 参考样片基线（用于核对，不是强制输出参数）
- 五段均约 5.17 秒、24fps、4:3，并带 AAC 音轨。
- 前两段为 1920×1440，后三段为 1024×768，说明**内容正确比强求统一分辨率更重要**；若做合集再统一缩放。
- 样片含 `updream` 生成标记和平台水印；后续如用于公开发布，需另行确认素材与平台的使用许可。

## 第 6 步：验收，决定通过或返工

### 输入
- 生成草稿、原关键帧、镜头表和确定台词。

### 操作：完整播放一次，再重点检查三项

**A. 画面**
- 首帧和整体风格是否仍像课本原图。
- 主动作是否清楚，是否有明显闪烁、穿模、多余肢体、人物突然替换。
- 是否出现不需要的新角色、新物体或镜头切换。

**B. 数学与文字**
- 动物、人物、花朵等教学对象的数量是否与原图一致。
- 数字、算式、门牌、对话气泡是否被改写；关键教学文字出错一律不通过。
- 圆/方、左右、多少、前后等关系是否仍正确。

**C. 配音**
- 台词是否逐字正确、完整、清楚，角色是否对应。
- 语速是否适合一年级，是否明显抢话或结尾被截断。
- 无台词镜头是否误加了不需要的旁白。

### 处理规则
- **通过：** 进入成片区。
- **轻微问题：** 台词错则重配；运镜过快则降低运动幅度；构图漂移则加强“保持首帧构图”。
- **重做：** 数量改变、数字/算式错误、核心角色换掉、教学含义改变。
- **改走稳妥路线：** 连续两次仍破坏数学内容时，不再抽卡，改用静态关键帧 + 缓慢推近/局部高亮 + 外部配音。

### 产出
- 验收状态：`通过 / 返工 / 改静态动效`。
- 一段可交付的短片。

## 第 7 步：命名、归档与可选合并

### 输入
- 通过验收的视频、关键帧、镜头表和生成记录。

### 操作
1. 在原课件目录建立 `_视频化`，将关键帧、草稿、成片和外部音频分别归位。
2. 按下方规则重命名最终成片，并在制作记录中填写最终文件名与验收状态。
3. 保留原 PPT、已有参考样片和生成草稿，不覆盖、不混放。
4. 仅在需要连续播放时，按镜头序号执行可选合并。

### 目录结构

在原 PPT 所在课时目录下新建 `_视频化`，不移动原文件：

```text
1我上学啦/
├─ 0.1 可爱的校园.pptx
├─ 视频 1_1029_153237.mp4        ← 已有参考样片，保留
└─ _视频化/
   └─ 0.1 可爱的校园/
      ├─ 01_关键帧/
      │  └─ S04_校园全景.png
      ├─ 02_草稿/
      │  └─ 0.1_S04_02_v01.mp4
      ├─ 03_成片/
      │  └─ 0.1 可爱的校园_S04_02_数一数小兔.mp4
      ├─ 04_音频/                ← 仅外部配音时需要
      └─ 制作记录.md              ← 页面清单、镜头表、提示词与验收结果可合并在这一份
```

### 命名规则

```text
成片：PPT编号 课题_S两位页码_两位镜头序号_简短内容.mp4
草稿：镜头ID_v两位版本号.mp4
关键帧：S两位页码_简短内容.png
```

- 页码和序号均补两位，保证按名称排序就是播放顺序。
- “简短内容”控制在 4～10 字，不写整句台词。
- 只有草稿带 `v01/v02`；成片区只留最终版，避免课堂误开。
- 不覆盖已有参考视频；如需替换旧成片，先将旧版移回草稿区。

### 可选合并
- 只有需要连续播放时，按镜头序号合并为 `0.1 可爱的校园_课时合集.mp4`。
- 合并前统一画幅和音量；4:3 素材放入 16:9 时使用背景填充，不拉伸。
- 默认直接顺接，不加复杂转场；保留提问后的思考停顿。

### 产出
- 可播放的独立短片或课时合集。
- 能据制作记录重新生成的完整档案。

## 三、五个参考样片如何映射到本流程

| 参考视频 | 可观察到的镜头设计 | 配音识别结果 | 复用价值 |
|---|---|---|---|
| 视频 1 | 校园全景，环境与角色轻微活动 | 未识别到清晰人声 | 适合作导入，不必每段都有台词 |
| 视频 2 | 左侧小熊指向小兔，全景基本固定 | “数一数有几只小兔。” | 一个指向动作 + 一个观察问题 |
| 视频 3 | 保持校园场景，突出跳房子相关角色 | “小学也有跳房子游戏呀。” | 课本原对话直接转口语配音 |
| 视频 4 | 从皮球附近近景拉回校园全景 | “球是圆圆的，门是长的，方方的。” | 运镜服务形状观察；整理台词时可保留原意并补足自然停顿 |
| 视频 5 | 前景出现思考的小熊，背景保持校园 | “在幼儿园我是大二班的，现在我是在哪个班呢？” | 可为了对话增加前景角色，但须是教学设计需要，不能默认乱加 |

这些样片说明流程可以很简单，但也暴露了必须验收的问题：AI 可能改动气泡文字、门牌和细节，甚至新增角色。因此后续课本 PPT 不能把“生成成功”直接当作“可课堂使用”。

## 四、复用到其他课本 PPT 时只改这些内容

### 每份新 PPT 必换
1. PPT 编号、课题和来源路径。
2. 候选页码与页面类型。
3. 关键帧图片和画幅。
4. 每个镜头的教学目的、主动作、台词、数量与文字约束。
5. 成片文件名中的编号、页码和镜头序号。

### 保持不变
- “选页 → 关键帧 → 单镜头表 → 图生视频 → 三项验收 → 命名归档”的顺序。
- 一镜头一动作一句台词、默认约 5 秒的低投入原则。
- 数学内容出错即返工、连续失败改静态动效的兜底规则。
- 目录结构、命名规则和制作记录字段。

### 推荐批量节奏
1. 新课件先做 1～3 个不同类型镜头。
2. 检查平台是否能稳定保持该教材画风、人物和文字。
3. 将成功提示词保存为本课件的固定写法，再处理其余候选页。
4. 每批生成后集中验收，不让草稿与成片混放。

## 五、最简执行清单

```text
□ 原 PPT 未修改，已建立 _视频化 子目录
□ 只选情境和观察重点明确的页面
□ 关键帧清晰，数量、文字、比例正确
□ 镜头表已填写：一个主动作、一句台词、限制条件
```
