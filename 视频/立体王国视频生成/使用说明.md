# 立体王国导入视频 —— 使用说明

## 成片（可直接用）
- `立体王国导入视频_预览版.mp4` —— 1920×1080 / 30fps / 3分54秒 / 真AI动态画面+全片配音（156MB）
- `立体王国导入视频_预览版.srt` —— 同步字幕（剪映导入即可显示）

结构：12 个镜头按七场景脚本排列；镜头 4/5/7/9/11 是提问镜头，
旁白结束后自动留 3~3.5 秒静默——课堂上此处按暂停让学生回答。
（对应关系：镜头4=认图形，5=线索"会滚"，6=球否认，7=线索"会滚+能立"，8=圆柱否认，
9=线索"不滚+面有长短"，10=长方体否认，11=终极提问，12=揭晓庆祝）

## 素材（可拿去二次加工）
- `shots/01~12_*.mp4` —— 12 段真 AI 视频原始素材（智谱 cogvideox-flash 图生视频，免费）
- `shots/01~12_*.jpg` —— 12 张 AI 首帧图（cogview-3-flash，免费）
- `shots/01~12_clip.mp4` —— 单镜头成片（真AI视频循环铺满+配音，剪映可单独加工）
- `audio/01~12.wav` —— 12 段角色配音（Windows Huihui TTS；魔法师语速-4，小客人语速+3）
- `narration.json` —— 全部台词，改完重跑两个脚本即可重新出片

## 重新生成
```
powershell -NoProfile -ExecutionPolicy Bypass -File make_tts.ps1   # 1. 重新配音
python build_final_video.py                                        # 2. 重新合成
python build_final_video.py -c                                     #    只重新拼接已有片段
```
改台词：编辑 narration.json。

## 重新生成 AI 视频素材
```
python generate_videos.py --stage videos --quality speed    # 全部 12 个镜头
python generate_videos.py --shots 5 --stage videos          # 只重做镜头5
```
- 模型：cogvideox-flash（免费，实测本账户可用；单段约5秒、720p，合成时自动放大到1080p并循环）。
- 收费模型 cogvideox-3/2 需要单独的视频资源包或余额（当前账户报 1113；编程套餐不覆盖视频 API）。
- 重做某个镜头：删掉 state.json 里 videos 下对应条目和 shots/NN_*.mp4 再跑上命令。
- 重做后执行 `python build_final_video.py` 重新出片。
- 想替换成即梦/可灵生成的片段：覆盖同名 `shots/NN_名称.mp4` 后重新跑 build 即可。

## 已知可优化点（公开课前建议）
1. 配音是 Windows 本地 TTS（Huihui），正式使用建议在剪映里换更自然的音色，字幕用 SRT 直接导入。
2. 旁白较长的镜头（3/4/5/9），5 秒 AI 素材会循环 4~8 次，衔接处有跳切；可在剪映里给这些
   镜头补一两个备用片段（重跑生成会出新画面），或加转场弱化。
3. 名牌（长方体/正方体/圆柱/球）建议在剪映里用贴纸加在镜头4，不要让 AI 生成文字。
