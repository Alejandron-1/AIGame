# 贴图小视频生成器（背景不动 + 贴图左右摇 + 念台词）

**成片：`小样_贴图视频.mp4`**（1080p/30fps，约 12 秒小样，双击播放）

## 它做什么
每段视频 = 一张**背景图**（全程不动）+ 一张**贴图 PNG**（像贴纸一样左右摇摆、轻微晃动）+ Windows TTS **念台词** + 底部大字幕。多段台词自动拼成一个视频。

## 怎么用
1. 改台词：打开 `小样_贴图视频.py`，改最上面的 `LINES`：
   ```python
   LINES = [
     {"voice": "Huihui", "rate": 0, "text": "第一句台词"},
     {"voice": "Huihui", "rate": 3, "text": "第二句台词"},
   ]
   ```
   voice：`Huihui`=中文女声，`Zira`=英文女声；rate：-10~10 语速。
2. 换素材（可选）：替换同目录的 `小样_背景.png`（1920×1080）和 `小样_贴纸.png`（透明底 PNG，比如抠好的卡通人物、教材插图）。
3. 运行：`python 小样_贴图视频.py` → 出 `小样_贴图视频.mp4`。

## 可调参数（脚本顶部）
- `SWING`：左右摆动幅度（像素，默认 30）
- `PERIOD`：摆动周期（秒，越小摆越快）
- `LEAD / TAIL`：每段台词前后静音秒数

## 台词多、角色多怎么办
- 加多少句都行，LINES 里一直往下加，自动按配音时长分配每段长度。
- 想换角色声音：目前系统只装了 Huihui（中文）和 Zira（英文）两个音，中文不同角色可用 rate 语速区分（如魔法师 -3、小客人 +3，参考《立体王国导入视频》的做法）。
- 想要更自然的童声：把剪映里配好的音频覆盖 `demo_tts_N.wav` 再跑（脚本会直接用现成 wav）。

## 依赖
- `视频/ffmpeg.exe`（已在本目录）
- Windows 自带 TTS（无需联网）
