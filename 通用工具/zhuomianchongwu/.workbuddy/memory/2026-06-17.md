## 班级管理模块（独立 classes 表 + 学生从属班级）

需求：用户要求管理员端有独立"班级管理"，且学生管理应从属于班级。

**数据库改造**（db.js）：
- 新增 classes 表（id/name/grade/is_active/sort_order/created_at/updated_at）
- students 表加 class_id 外键（ON DELETE SET NULL），保留 class_name 兼容旧前端
- migrate()：老库 ALTER TABLE 加 class_id 列；把现有 distinct class_name 自动建 classes 记录并回填 class_id
- 坑：CREATE INDEX ON students(class_id) 不能放在 initSchema（老表没这列会报错），移到 migrate 里 ALTER 之后建
- seed 默认数据先建"三年二班"班级记录，学生绑定 class_id

**后端路由**：
- 新增 routes/classes.js：GET列表(带student_count)/POST/PUT/DELETE(学生置NULL)/GET :id/students
- students.js 改造：GET 支持 class_id/unassigned 过滤；POST/PUT 支持 class_id（自动同步 class_name）；import 支持 ?class_id= 强制归入指定班；export 支持 ?class_id= 只导该班
- server.js 挂载 /api/classes

**管理端 UI**：
- admin.html 导航：把"学生管理"改为"班级管理"
- admin.js：VIEWS.classes 实现 左班级列表+右学生列表联动布局；classState 管理选中班级；支持班级CRUD、学生CRUD、换班(moveStudent)、导入到指定班、导出班级学生
- admin.css：.class-layout/.class-side/.class-main 分栏布局，窄屏自动转纵向
