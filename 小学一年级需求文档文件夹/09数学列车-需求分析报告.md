## 二、可直接采纳、无需追问的部分（文档写得好的地方）

1. **三段式界面骨架**：顶部导航（返回 + 标题 + 三关 Tab + 声音开关）/ 主内容区 ≥80% / 底部任务提示区——清晰可落地。
2. **反馈规范**：正确 = 放大 + 绿色高亮 + "叮"声 + 表扬语；错误 = 左右摇晃 + 低沉提示音 + 不扣分可重试——规范明确、符合低段教学。
3. **关卡三判定算法**：`目标数字 = 10 - 6 + 1 = 5`，正确无误，可直接实现。
4. **技术约束**：点击热区、300ms 防抖、60FPS、SVG 矢量、完全离线、教师隐藏控制台。
5. **优先级划分**：P0 三关完整逻辑+基础 UI+对错反馈+语音播报；P1 动画+随机出题；P2 音效+语音识别。
6. **三关的教学目标定位准确**：数量对应 / 数序 / 基数与序数，正好对应人教版一上"11~20 各数的认识"前置与"第几"单元。

## 三、问题清单

### A. 阻断级问题（不确认无法开发）

| 编号 | 问题 | 为什么是问题 | 建议默认值 |
|---|---|---|---|
| **A1** | **参考图 1~4 全部缺失** | 文档 4 处写"参考图1""对应图2/3/4"，但 md 文件内没有任何图片或链接。界面布局、图形素材、题目排布全靠脑补 | 按文字描述**自绘 SVG 卡通素材**（向日葵/尺子/火车）；或由你补图后再定稿 |
| **A2** | **"刷新按钮"存在性自相矛盾** | 2.1 顶部导航只列了"返回 / 标题 / Tab / 声音开关"，2.2 重置机制却说"点击刷新按钮" | 顶部右侧增加 `🔄 重来` 按钮（当前关卡重置） |
| **A3** | **关卡一提示语泄题** | 2.2 与关卡一都写"根据点亮的圆圈数，底部提示'点击X个点子'"。若 X = 目标数量，等于**直接把答案念出来**，教学目标当场失效 | 改为过程性文案：`你点了 3 个，再数一数哦`；答错 3 次后才升级为支架提示 `一共要点 7 个` |
| **A4** | **关卡一数字选项生成规则未定义** | 文档写"四个数字选项（例如：7、8、9、10）"，但数量范围是 6~10。**当物体数为 6 时，{7,8,9,10} 里没有正确答案**，题目无解 | 正确答案 + 3 个干扰项（在 ±2 内取，限定 1~10，去重后打乱） |
| **A5** | **关卡一两个通关条件的先后与组合未定义** | "点亮圆圈数 = 物体数" 且 "选中数字 = 物体数" 才通关。但：数字按钮在点完圆圈前能否点？只满足其中一个条件时给什么反馈？ | 两步顺序解锁：先数点子（点亮数正确才解锁数字按钮，或允许随时点但两条件同时满足才判对）；只满足其一时提示"你数的数对了，再看看是数字几？" |
| **A6** | **关卡二备选数字生成规则未定义** | 示例固定为 `6、7、8、9、10`，但隐藏数字是随机 0~10。**若隐藏的是 0 或 2，这套选项里没有正确答案** | 5 个选项 = 正确数 ±2 滑动窗口（越界自动补邻），必含正确答案 |
| **A7** | **关卡三"方向"表述矛盾 + 火车头朝向未定义** | 文档写"左边 →"和"← 右边"。箭头到底表示"从左边开始数"还是"从左往右的视线"？同时未说明**火车头在左还是在右**——"从右边数"能不能数到车头，直接改变语义 | 统一为文字"**从左往右数 / 从右往左数**"；固定火车头在**左**，车厢 1~10 从左到右排列，方向指示用一条从左到右的虚线轨道 + 文字标注 |
| **A8** | **车厢已预印 1~10，序数教学被架空** | 目标"第 6 节"实际是编号 5，但车厢上写着 5 和 6 两个数字，学生只要从右往左**倒数格子**或直接看编号即可，"第几"的理解被跳过 | 做**两档难度**：★易 = 车厢带编号；★★难 = 车厢不印编号（需学生自己数格子）。默认进关卡时出"易"，连对 3 题自动升"难" |
| **A9** | **关卡三文案错误** | "从右边数，第6**只**表示这一节"——"只"应为"节"，"表示"应为"是"；且这句既是指令又被写成答对后的反馈文字，**指令与反馈文案重复** | 指令统一为：`从右边数，第 6 节车厢——是哪一节？`；答对后反馈改为 `答对啦！从右边数，第 6 节就是它 🎉` |
| **A10** | **题量 / 进度 / 通关 / 是否计分 全未定义** | 全文没有"一轮几题""答对几题算通关""结束后做什么"。P0 却要求"完整逻辑"——没有终点就没有完整逻辑 | 每关 **5 题一轮**；进度条主题化：**答对 1 题给火车挂 1 节车厢**，5 节集齐小火车鸣笛开走 + 庆祝动画；不做分数排名（符合 08 文档"不引入失败惩罚/不排名"原则） |
| **A11** | **"自动下一题"与"老师手动下一题"并存未定** | 2.2 同时写了"自动进入下一题**或**由老师手动点击下一题"，二选一没说 | 答对后延迟 **1.2 秒自动**进入下一题；同时在右上角常驻 `⏭ 下一题` 按钮供老师随时手动跳题 |
| **A12** | **语音方案与"完全离线"要求冲突，且无任何音频素材** | 要求"自动朗读指令"（2.2）+ "完全离线，本地加载音频"（四.4），但项目里没有任何配音文件；若用浏览器 TTS，则依赖系统语音包；若用在线 TTS，则违背离线 | 默认用 **Web Speech API（zh-CN）**实时合成（Windows/macOS 自带中文语音，实测离线可用）；不可用时**静默降级**为屏幕大字提示 + 提示音。预留 `audio/` 目录可后续替换为预录配音 |

### B. 体验级问题（影响课堂可用性）

| 编号 | 问题 | 建议默认值 |
|---|---|---|
| B1 | 关卡一：点亮的圆圈能否再点取消？点错如何撤销？点满 10 个后怎么办？报数音效在取消时是否回退？ | 支持再点取消（报数由 1 连续重新编号）；提供 `清空` 小按钮；点满 10 个仍可取消 |
| B2 | 关卡一：10 个圆圈是 5+5 还是 4+6？物体种类未定义（只有向日葵？每轮是否更换？） | 固定 **5+5 两排**；物体池 = 向日葵 / 苹果 / 小鱼 / 星星 / 气球，每轮随机一种并整轮统一 |
| B3 | 关卡二：隐藏范围是否含 0 和 10 端点？答对飞入动画后是否自动下一题？ | 隐藏范围限定 **1~9**（避开端点歧义）；动画结束后同 A11 节奏推进 |
| B4 | 关卡三：指令随机范围？答错是否直接给答案？能否无限重试？ | 范围 **第 1~8 节**（避开贴边的 9/10）；答错**不给答案**，改给过程提示（"从右边开始数：1、2、3…"并让轨道箭头逐格指点），错 3 次后才高亮正确车厢 |
| B5 | "切换 Tab 即完全重置"与课堂节奏冲突 | 切 Tab **保留当前题进度**，`🔄 重来` 才重置当前关卡（A2 的按钮） |
| B6 | 声音开关在 MVP 里是否能生效？ | 音效提为 **P0**（纯 Web Audio 合成，零成本），使声音开关与 P0 一致 |
| B7 | "支持多点触控（大屏）"与"两次点击间隔 >300ms 防抖"相互制约 | 防抖只作用于**同一元素的重复点击**；不同元素的多点触控正常放行 |
| B8 | 平台冲突：文档要平板 iOS/Android，项目规范是"桌面优先、不做响应式"；也未给分辨率基准 | 以 **1920×1080 大屏为基准**、1280×720 可用；不做移动端适配（与现有 15 款游戏保持一致） |

### C. 工程与资源

- **C1 音频素材缺失**："叮"声、低沉提示音、报数音效、背景音乐全部无文件 → 建议用 Web Audio API 程序合成（本项目现有游戏已有同类做法，零素材、零版权风险）。
- **C2 表扬语音**："太棒了！"等无配音 → 交给 TTS 朗读，不引入音频文件。
- **C3 无持久化**：文档未提，建议**保持"刷新即重置"**，与 08 文档"不做本地存储，防止课堂公用电脑脏数据"一致。
- **C4 未约束"同轮不重复出题"** → 增加"同一轮内不出重复题目"的约束，避免连续两次隐藏同一个数字。
- **C5 与既有游戏重复度（重要）**：
  - 关卡一"数量与数字" ≈ 已上线的 `看图说数字.html`（10 以内数数），差异仅在 6~10 与"点数点子"机制；
  - 关卡三"第几节车厢" ≈ 已上线的 `排队找第几.html`（序数 + 左右方位）；
  - **关卡二"尺子上的数"是全项目首个"数轴/数序"内容，教学价值最高、最不应被砍**。
  - 建议：三关全做，但把**关卡二作为默认落地页**，并在游戏目录里把该作的定位写成"6~10 数概念 + 数序专项"，与既有两作错开描述。

## 六、结论与建议流程

按项目既有工作流 —— **文档 → 分析优化 → 单文件 HTML → 实测验收** —— 本报告即"分析优化"阶段的产出。

文档骨架可用、教学目标正确、算法无误，但**细节缺口足以导致开发返工**（尤其 A1 参考图、A4/A6 选项生成、A8 车厢编号、A10 题量与通关）。建议：

1. 你确认上表默认值（或指出需要改的项）；
2. 我按确认结果实现 `小学一年级/数字列车.html`（复用 `看图说数字` 的浅色课本风 + `排队找第几` 的左右/序数逻辑 + `认识钟表` 的大屏字号规范）；
3. 同步注册到根目录 `index.html`（游戏目录），并做一轮实测验收。
