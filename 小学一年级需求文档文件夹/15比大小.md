## V2.0 需求（现行）

1. **界面**：左右两个大圆角卡片（左橙/右蓝）各显示一组图案，图案类型左右不同（emoji 池 12 种随机两种）；中央一个「?」圆。
2. **出题**：每侧数量独立随机 1~10（可能相同也可能不同）；只显示「第 N 题」。
3. **答题**：三个大按钮「＞大于」「＝等于」「＜小于」。
   - 答对：按钮变绿、其他变淡、中央「?」变符号+读法（如「＞ 大于」）、两侧亮出「N 个」、音效+语音「5 大于 3」。
   - 答错：按钮抖动 + 鼓励提示「再想一想，数一数两边各有几个～」，不锁定可重选。
4. **自动下一题**：答对 2 秒后自动出新题（`CONFIG.NEXT_MS`，代数戳防连点串题）。
5. **保持极简**：不添加设置、计分、计时、排名等任何额外功能。
6. 教师隐藏快捷键照旧：`空格`=下一题、`R`=换一题、`A`=显示答案、`Esc`=返回目录。
7. 回归测试：`test_bidxiao.js`（37 断言，覆盖出题不变量、答错/答对分支、自动下一题、代数戳防串题）。

# 存档 · V1.0（一一对应配对版，已被 V2.0 取代）

> 素材来源：小红书 @Re老师会AI 课堂截图 ×5（2026-09-20）
> 定位：一年级上册「比大小」（<、=、> 第一课），用**一一对应**作比大小的算理基础。

## 1. 游戏目标

学生通过「一个对一个连线」直观判断两组物体谁多谁少，再选出正确的比较符号
`<` `=` `>`，建立「比大小先数数、符号开口朝大数」的直觉。

## 2. 截图实证（必须还原的要素）

| 截图要素 | 说明 |
|---|---|
| 顶栏提示 | 固定文案：「一个对一个，用点线连起来；看看哪边有多出来的。」 |
| 左右两栏 | 左栏物体一种（如兔子），右栏另一种（如萝卜），栏顶各有一个示例图标 + 「左边」「右边」标签 |
| 中间「一一对应」 | 配对成功的两行之间显示点线「······」 |
| 未配对高亮 | 没有伙伴的物体套**黄色虚线框**（截图 2 的松果、截图 4 的 3 根萝卜） |
| 结论句 | 三选一：「左边有对象没有伙伴，所以左边多。」/「右边有对象没有伙伴，所以右边多。」/「每一个都有伙伴，两边同样多。」 |
| 大算式 | `5 > 1` 形式，两数字 + 中间符号；正确符号显示为红色 |
| 符号按钮 | `<` `=` `>` 三个白色圆角按钮，答对后该按钮变绿 |
| 底部句 | 「左边多，右边少，5 > 1。」/「两边同样多，2 = 2。」 |

截图覆盖的题型：左多（5>1、4>2）、右多（4<5、2<5）、相等（2=2）——三种都要出。

## 3. 交互流程（截图未拍到的部分，拍板如下）

**三阶段，与截图画面一一对应：**

1. **连线配对阶段**（截图上半部分）
   - 左右两栏物体竖排展示，**不显示数字**（逼迫学生用对应而不是数数？不——保留数数自由，
     但数字在配对完成前不出现在算式区）。
   - 学生**点 1 个左边物体 → 再点 1 个右边物体**，两个物体之间生成一行「······」点线，
     两个物体同时变为「已配对」样式（对勾小圆点标记）。
   - 点已配对的物体 = 拆散这对（点线消失，可重新配），防手滑。
   - 支持乱序配对（不必从上往下），点线行跟随先点的物体所在行。
2. **自动结算阶段**（截图的黄框 + 结论句）
   - 当某一边全部配完（另一边还有剩），剩余物体自动套黄色虚线框，结论句出现。
   - 相等情形：全部配完后无黄框，显示「每一个都有伙伴，两边同样多。」
   - 此时大算式区亮出两个数字：`5 ⬜ 1`，中间符号位为空槽。
3. **选符号阶段**（截图下半部分）
   - 学生点 `<` `=` `>` 之一：
     - 答对 → 按钮变绿、算式符号位填红色符号、底部句子出现、庆祝音效 + 语音读句。
     - 答错 → 按钮抖一抖，不惩罚不锁死，可再选（符合课堂原则：错误不惩罚）。
   - 答对后出现「下一个 →」按钮进入下一题。

**防呆**：配对没完成时，符号按钮置灰不可点（避免瞎蒙）——这是和截图唯一不同的主动加固，
截图是演示完成态。

## 4. 出题规则（拍板数值）

- 物体对池（左右各一种，成对出现）：兔↔萝卜、松鼠↔松果、小鸡↔玉米、猫↔鱼、熊猫↔竹子、
  猴子↔桃子、青蛙↔荷叶、蜜蜂↔花朵（8 组轮换）。
- 数量：左边 1~10、右边 1~10 独立随机；相等题保证两边同数（2~10）。
- 题型分布：左多 40% / 右多 40% / 相等 20%（相等题必须稳定出现，不能总抽不到）。
- 差值不限（可 5>1，也可 6>5），贴近截图的悬殊与接近两种形态。
- **不出现 0**（一年级第一课不涉及 0 的比较）。

## 5. 支架与提示（不泄答案红线）

- 连线阶段卡住 10 秒无操作 → 轻提示：「点一个左边的，再点一个右边的，它们就是一对。」
- 选符号错 2 次 → 支架提示：「看黄框在哪一边，黄框多的那边物体多。」（只给方法不给符号）
- 相等题选错 2 次 → 「每个都有伙伴，就是一样多。」
- **任何提示不直接说出该按哪个符号。**

## 6. 设置面板（⚙ 按钮，存 localStorage）

`localStorage['bidxiao_settings']`
- 数字范围：1~5 / 1~10（默认 1~10；快捷预设按钮）
- 相等题：出 / 不出（默认出）
- 自动读题：开 / 关（默认开，新题读顶栏提示语）

## 7. 教师功能（常驻隐藏控制台，沿用全局约定）

- `空格` = 下一题；`R` = 重来本题；`A` = 显示答案（自动配对完成 + 正确符号绿色高亮）；
- `Esc` = 返回目录。快捷键不影响正常点击。

## 8. 视觉与音频

- 1920×1080 大屏基准，浅色课本风 + 明亮糖果色（与分与合/算式工厂同家族）；
  无滚动条、字号大、按钮点击区域 ≥ 80px。
- 物体用纯 CSS/SVG 绘制（延续小鸡纯 CSS 的做法），不引外部图片。
- 音效 Web Audio 合成（配对「嗒」、答对上行琶音、答错低音「噗」）；
  语音 Web Speech API zh-CN（rate≈0.85）读结论句，API 不可用静默降级，全部 try/catch。
- 一局 2~3 分钟约 3~4 题；不计时、不排名、不写 localStorage 存进度（设置除外）。

## 9. 验收标准

1. 三种题型（左多/右多/相等）都能出、都能玩通。
2. 配对→黄框→结论句→选符号→底部句，顺序与截图一致。
3. 拆散重配、答错重选、防呆置灰均正常。
4. Node DOM 桩回归测试通过（配对逻辑、结算判断、符号判定、支架阈值）。
5. 注册进根目录 index.html 游戏目录。
