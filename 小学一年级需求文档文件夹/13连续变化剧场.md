# 《连续变化剧场》需求文档 V1.0 —— 6~10 加减法 · 两步连续变化应用题

> **适用**：一年级上册 第五单元「6~10 的认识和加减法」中的连加、连减与加减混合（两步应用题首次出现处）
> **形态**：单文件 HTML（`小学一年级/连续变化剧场.html`），CSS/JS 全内联，零依赖、断网双击可用，以 1920×1080 教室大屏为基准
> **来源**：依据教师提供的 3 张课堂截图还原界面与玩法（小红书 @Re老师会AI《26 秋新版数学 一上 6-10 的加减法》，应用内标题"连续变化剧场"），并补全截图中未定义的数值与规则
> **定位**：**事理理解 → 数量链 → 完整算式**的三层进阶。项目现有口算游戏（数学拔河 / 数学赛车 / 飞驰人生）练的都是"一步算得数"，本作练的是教材"解决问题"课时的核心——**按事情发生的顺序，把一次连续变化拆成两步看**：先看懂发生了什么（事理），再填出每一步之后还剩/一共有几（数量），最后选出完整算式（符号）。这是后续学习"大括线两步应用题"的直接基础。

## 一、教学目标（一节课要带走的三件事）

| # | 目标 | 在游戏里怎么达成 |
|---|---|---|
| T1 | **看懂事理**：一次变化里有两件事，按顺序发生 | 「▶ 第一次变化」「▶ 第二次变化」两个回放按钮，把连续过程拆成两段动画分开看 |
| T2 | **会说数量**：每一步变化后，都数得出"现在有几只" | 数量链条 `原来 N只 → 第一次后 ?只 → 最后 ?只`，学生亲手把两个 `?` 填上 |
| T3 | **会列算式**：把两步变化写成一个完整算式 | 三选一选完整算式，干扰项专门针对"只算第一步""得数算错"两类典型错误 |

> T1→T2→T3 是强制的先后顺序（见第三节），对应截图三句提示语：`按事情发生的顺序，先看第一次变化，再看第二次变化。` → `两次变化都看完了，请选择完整算式。` → `两次变化都写对了，再检查最后的得数。`

## 三、主玩法：三阶段强制顺序

一道题 = 一次剧情。三个阶段必须依次完成，前一阶段没完成，后一阶段的控件置灰不可点（截图 1 实证：未看变化时算式区整排灰色、`▶ 第二次变化` 也未解锁）。

### 3.1 阶段一：看变化（事理层）

- 进入新题，场景中先呈现**原来**的小鸡（`N` 只），题目条与语音读题一遍
- 点 `▶ 第一次变化`：A 只小鸡按题意**跑走来/跑走**（跑来 = 从画面右侧走入队列；跑走 = 从队列飞出画面），动画约 1.5s，期间控件全部暂时禁用
- 第一次动画播完前，`▶ 第二次变化` 保持置灰；播完后解锁
- 点 `▶ 第二次变化`：B 只小鸡同样演出
- 两个按钮看完后可**随时重播**任意一段（反复观察是权利，不是错误）
- 阶段提示语（同步语音）：`按事情发生的顺序，先看第一次变化，再看第二次变化。`
- 两段都看过 → 自动进入阶段二，提示语切换为：`两次变化都看完了，把每一步后的只数填进链条吧。`

### 3.2 阶段二：填数量链（数量层）

- `原来 N只` 框开场就显示数字；`第一次后 ?只` 与 `最后 ?只` 显示大号 `?`
- 点任意 `?` → 弹出 **0~10 数字选盘**（居中小弹窗，11 个大按钮）→ 点数字填入
- **填错**：`?` 框摇晃 + 柔和低音，提示条温和提示，可重选（数字盘不关，直接改）；**不扣分、不报错红**
- **填对**：`?` 变成绿色实心数字并锁定（带「叮」上行音）
- 两个 `?` 都填对 → 算式三选一解锁（灰色 → 正常），提示语切换为：`两次变化都写对了，请选择完整算式。`
- 填对顺序不限（可以先填"最后"再填"第一次后"——但答错时的支架提示会引导按顺序数）

### 3.3 阶段三：选完整算式（符号层）

- 三张算式卡片（生成规则见第四节），点选判定：
  - **选对**：卡片变绿 + pop 动画 + 欢呼音 + 全体小鸡集体跳跃；语音读完整算式 `7 减 4 减 1 等于 2`；1.2s 后自动进入下一题（`⏭ 下一题` 按钮常驻可提前）
  - **选错**：卡片变**粉色** + 摇晃（截图 3 实证），可继续选其他卡片，不扣分
- **针对两类干扰项的差异化提示**（选错后提示条切换，同步语音）：
  - 选了"只算第一步"（如 `7 - 4 = 3`）→ `这只算了第一次变化，第二次变化还没算哦。`
  - 选了"得数算错"（如 `7 - 4 - 1 = 3`）→ `算式选对了，再检查最后的得数。`

## 四、出题规则（全部拍死，开发直接照此实现）

### 4.1 题型三档（对应 ⚙ 设置的难度）

| 档 | 类型 | 算式形态 | 示例 | 定位 |
|---|---|---|---|---|
| ★ | 来了又来（连加） | `N + A + B` | `5 + 3 + 1 = 9`（截图 2） | 最易，数量只增不减 |
| ★★ | 走了又走（连减） | `N - A - B` | `7 - 4 - 1 = 2`（截图 1/3） | 数量只减不增 |
| ★★★ | 有来有走（加减混合） | `N - A + B` 或 `N + A - B` | `6 - 2 + 3 = 7` | 先减后增/先增后减，打破"越走越少"定势 |

### 4.2 数值约束

| 项 | 取值 |
|---|---|
| 原来 N | 5 ~ 10（默认从 5 起，与截图 2 一致；`⚙ 设置` 可限定范围） |
| 变化量 A、B | 各 1 ~ 4，且 A ≠ B 时优先（A = B 也允许，避免无题可出） |
| 第一次后数量 | 0 ~ 10 之间（走时不低于 0，来时不超 10） |
| 最后数量 | 0 ~ 10 之间，**且 ≥ 1**（不出现"全部走光"的 0 结果题，避免与"清空"歧义） |
| 动物 | 默认小鸡（CSS/SVG 绘制，圆身 + 橙嘴 + 小翅，还原截图造型） |

### 4.3 算式选项生成（三张，必含正确答案）

| 位置 | 内容 | 设计意图 |
|---|---|---|
| 干扰项 1 | **只算第一步**：`N ± A = 第一次后的数量`（如 `7 - 4 = 3`） | 针对典型错误"看漏第二次变化"，且与数量链第一次后的绿数字互相印证 |
| 干扰项 2 | **完整算式、得数错**：与正确算式同形，得数 = 正确得数 ±1（如 `7 - 4 - 1 = 3`） | 针对典型错误"算式对但算错"，截图中两者同时出现（7-4=3 与 7-4-1=3），照此还原 |
| 正确项 | 完整算式 + 正确得数 | 三张随机打乱排位 |

- 得数错的 ±1 方向随机；若 ±1 后恰好等于"只算第一步"的值也照常出（截图 1 正是如此：两个 3 并存，算式不同）
- 算式中的运算符、数字与题目描述严格对应（跑来 = `+`，跑走 = `-`），杜绝"货不对板"

### 4.4 一轮与进度

- **5 题一轮**，顶栏下方显示进度 `小鸡回窝 x/5`（温和进度条，不显示分数）
- 5 题全对 → 集体庆祝：全体小鸡排队走回树后小屋 + 撒花 + 鸣叫音；一轮内答错的题**不计入惩罚**（可无限重试，做对才算数）
- 一轮结束后回到同档位再出一轮，`🔄 重来` 只重置当前题

## 五、支架提示（卡住才给，绝不泄题）

| 触发 | 提示内容 |
|---|---|
| 阶段二同一题内填错 `?` **累计 3 次** | 提示条：`再点 ▶ 按钮，一边看动画一边数一数哦`，同时两个回放按钮脉冲发光（引导回看动画数数，不直接给数字） |
| 阶段三同一题内选错算式 **累计 3 次** | 提示条：`从"原来有几只"开始，按事情发生的顺序，一步一步想。`（只给方法路径） |
| 阶段三选错 **累计 5 次** | 高亮数量链两个已填对的绿数字 → 引导对照算式：`链条上的数都对得上吗？` |

> **门槛定在 3 / 5，而不是更激进的 2 / 4（D1，开发实测发现）**：选错算式时**每次**都会先给"这张卡片的针对性反馈"——`这只算了第一次变化…` 或 `算式选对了，再检查最后的得数。`（截屏里的教学重点就是这两句）。若把支架门槛设在 2 次，第 2 次选错时通用方法支架就会**盖掉**那句针对性反馈，恰好把两处截图的关键文案吃掉。改成 3 次后：第 1 次给"只算第一步"反馈、第 2 次给"得数错"反馈，第 3 次才升级为方法支架，第 5 次再升级为链条高亮，反馈与支架互不挤占。

- 支架提示每次出现同步语音朗读，同一题内各触发一次
- **任何情况下不直接说出答案或正确卡片位置**（沿用 09/12 两作的防泄题红线）

## 九、边界与异常

1. 走的数量不允许超过当前数量（出题时约束，运行期不会出现负数）
2. 动画播放心点回放按钮 → 忽略（动画期间全控件禁用）
3. `?` 数字盘点选时当前已填对的框不可再点（绿色锁定）
4. 选对算式后的 1.2s 内点其他卡片 → 忽略（busy 态）
5. 语音/音频 API 不可用 → 静默降级，逻辑不受影响
6. 断网双击文件可完整游玩，无任何外部请求；1920×1080 无滚动条
