# 《飞驰人生》3人竞速口算游戏 需求分析&开发文档

## 一、图片内容分析

### 游戏名称：飞驰人生｜20以内加减法口算小游戏

**定位**：课堂3人PK竞速答题课件，适合一年级，希沃大屏触屏操作。

1. **布局结构**：页面横向分为**3列独立玩家区域（学生1蓝、学生2红、学生3黄）**，三名学生同时各自答题，互不干扰。
2. 标题区（顶部）
   - 主标题：飞驰人生，搭配小车图标
   - 副标题：20以内加减法口算小游戏
   - 游戏规则文字：**最快答对10题就获胜！**
3. 每一列玩家板块内部
   - 玩家标识：彩色圆形 + 学生编号 + 【连击】标签（记录当前连续答对题数）
   - 题目卡片（蓝色框）：显示口算算式，例：`14-8=？`、`6+1=？`
   - 4个选项按钮（2行2列，四选一）：1个正确答案，3个随机干扰错误选项，点击选择答案
   - 底部赛道进度条：格子赛道，小车代表玩家。**答对一题，小车向前前进一格**，一共10格，走完10格直接胜利。
4. **题目范围**：**20以内加法、20以内减法**（含0参与运算，如`2-0`、`11+0`）
5. 核心玩法
   - 3个学生同时独立答题，各自赛道、各自题目（三人题目不一样）
   - 答对：小车前进一格，连击+1，自动刷新下一道新题目
   - 答错：小车不动，连击清零，保留本题，可以重新选答案作答
   - 谁率先答对满10题，小车跑到赛道终点，即为本局胜利者
6. **视觉风格**：深色星空背景，蓝色题目卡片，彩色玩家标识，小车竞速主题，适配大屏远距离观看，触屏大按钮。

# 二、完整开发需求文档

## 1. 项目概述

**项目名称**：飞驰人生 3人竞速口算小游戏 **适用学段**：小学一年级 **知识点**：20以内加减法口算 **运行环境**：纯前端HTML+CSS+JS，本地HTML直接打开，适配教学大屏、触屏+鼠标操作，无需联网、无后端。 **产品目标**：课堂三人PK互动游戏，三名学生同台竞赛口算，以小车前进作为可视化激励，提升课堂口算练习趣味性，适合公开课、课堂小组比拼。

## 2. 页面UI布局

整体页面分为【顶部标题规则区】+【三栏玩家面板（学生1/学生2/学生3）】

### 顶部区域

- 游戏名称：飞驰人生，搭配小汽车装饰图标
- 副标题：20以内加减法口算小游戏
- 规则提示文字：最快答对10题就获胜！

### 每一栏玩家面板（三栏结构完全一致，仅颜色区分）

1. 玩家头部信息
   - 圆形颜色标识：学生1蓝色、学生2红色、学生3黄色
   - 文字：学生1 / 学生2 / 学生3
   - 连击标签：显示当前连续答对数量，例如「6连击」，答错则重置连击为0
2. 题目卡片（蓝色大卡片）
   - 居中显示算式，格式：`a ± b = ?`
3. 4个答案选项（2×2四宫格按钮）
   - 1个正确答案，3个随机生成干扰错误选项
   - 按钮为浅色矩形，字体放大，适合手指触屏点击
4. 底部赛道进度区域
   - 横向赛道，一共10个格子
   - 对应颜色小车图标，代表玩家位置
   - 初始小车在起点（第0格）；**答对一题前进一格**，到达第10格，游戏结束，该玩家获胜

## 3. 出题规则

1. 算式范围：**20以内加法、20以内减法**，支持含0运算（如`11+0`、`2-0`）
2. 每一轮为三名学生**分别独立随机出题**，三人题目不相同
3. 选项生成：算出本题正确答案，再随机生成3个在合理区间的错误数字作为干扰项，4个数字打乱随机排布在四个按钮上

## 4. 游戏交互逻辑（核心）

> 三个玩家答题互相独立，互不影响

1. 游戏初始化

   - 三个玩家进度全部重置为0格，连击=0
   - 各自生成第一道随机口算题，小车停在赛道起点

2. 点击选项作答

   - ✅ 

     答案正确

     1. 小车向前移动一格
     2. 连击数 + 1，更新连击标签
     3. 判断：当前进度是否=10
        - 进度=10 → 弹出胜利提示：【学生X获胜！】本局结束
        - 未到10 → 自动刷新该玩家下一道全新题目

   - ❌ 

     答案错误

     1. 小车位置不变
     2. 连击清零重置为0
     3. 不切换题目，学生可以再次选择其他选项重试

3. 胜利判定：**任意一名玩家率先答对10题，小车走到赛道终点，本局游戏结束，宣告该玩家胜利**。另外两名玩家停止答题。

4. 重置游戏按钮：增加【重新开始】全局按钮，一键重置所有人进度、连击、题目，开启新一轮比赛。

## 5. 音效反馈（可选）

- 答对：轻快成功音效
- 答错：简短提示音
- 获胜：胜利庆祝音效

## 6. 视觉规范

1. 背景：深色星空简约背景，不花哨
2. 玩家配色：学生1蓝色、学生2红色、学生3黄色，整套面板跟随主色
3. 字体：粗圆黑体，字号大，大屏远距离可读
4. 按钮：大尺寸圆角矩形，触屏点击区域充足
5. 赛道：横向方格轨道，小车图标在格子内移动，直观可视化进度

## 7. 技术要求

1. 技术栈：HTML + CSS + JavaScript，纯前端，无需后端
2. 本地打开即用，不需要网络
3. 代码添加中文注释，方便后续修改：修改数字范围、题目难度、总目标题数（当前目标10题）
4. 同时支持鼠标、触屏操作，适配希沃一体机
5. 页面自适应16:9教学大屏

## 8. 功能优先级

✅ 必做

1. 三栏独立玩家面板，独立出题
2. 20以内加减随机算式，四选一随机打乱选项
3. 答对小车前进、连击计数；答错连击清零，不换题
4. 赛道一共10格，先到10格获胜
5. 全局【重新开始】重置整局游戏

❌ 本次不做

- 计时功能、排行榜、保存历史记录

## 9. 教学价值

多人同台PK模式，调动学生积极性；可视化小车前进，正向激励，适合口算巩固训练，公开课互动效果强。

## 10. 实现版说明（v1.1 优化记录，已实现）

1. **题目互异实现**：原文「三人题目不相同」在随机出题下无法长期保证，实现为「同一轮三人当前题互不相同」——生成时与其他两人当前题比对，重复则重新生成
2. **答错重试防瞎猜**：答错后题目保留可继续作答，但答错的选项按钮禁用（本题不能再选它），兼顾低龄包容与防暴力点穿；连击清零反馈保留
3. **胜利结算完善**：冲线后弹窗显示获胜方+三人各自的答对题数/正确率+撒花庆祝音效，全局锁定等待【再来一局】/【重新开始】
4. **出题范围**：加法 a+b≤20（含 0 参与，如 11+0）；减法 a≤20 且 b≤a（差非负，如 2-0），400 题抽样校验零越界
5. **干扰项规则**：非负、≤20、正确答案±1~5邻近值优先、四选项互不重复
6. 连击标签带弹跳动画；小车前进带加速动效；赛道第10格为格子旗终点
7. 音效按原文档可选要求实现：答对轻快音、答错简短音、获胜庆祝音
