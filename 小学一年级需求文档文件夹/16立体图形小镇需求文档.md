**我们要做的**：同款四段式骨架 + 同款扁平可爱画风，但**物品全部换成你自己的真实图片素材**（竞品是他手绘的），并且谜语、儿歌、情境物品直接用你 38 页课件里的原文，做到"课本无缝衔接"。

## 3. 游戏总设定

- **名称**：立体图形小镇（页面标题：🧱 立体图形小镇 · 认识立体图形 公开课版）
- **文件**：`小学一年级/认识立体图形-图形小镇.html`，单文件、零依赖、完全离线；全部图片经压缩后 base64 内嵌（预算 ≤ 700KB）
- **画风**：竞品同款扁平可爱风——米色纸感底色（#faf6ee）、粗描边圆角卡片、四个形状的专属色（长方体橙 #f5a35c / 正方体蓝 #7fb2e5 / 圆柱绿 #7fc8a8 / 球粉 #f2a6b8）、图形带笑脸腮红。**本作不用 Three.js**（与真 3D 的《互动课件》错位互补；竟品美感来自扁平插画，不是 3D）
- **音效**：沿用项目 beep 模板（点击/答对/答错/彩纸/颁奖号角）
- **翻页控制**：页面右侧固定四关卡导航点（教师可跳转任一环节，适应课堂节奏）；底部大号"下一关"按钮
- **与《认识立体图形-互动课件》关系**：主题相同、结构互补——旧课件是"真 3D 观察与拼搭教具"，本作是"贴课本流程的闯关游戏"；两者音效/规则代码复用，界面独立

## 4. 四关卡详细流程（核心章节）

### 第 1 关 · 认识小伙伴（实物变图形）

**教学意图**：从真实物品抽象到几何体（课本 P8→P10 的"实物→图形"关键一步）。

- **进场画面**：米色网格地面舞台，8 件实物照片随落座动画摆成两排（每形状 2 件：纸箱、抽纸盒、魔方、骰子、垃圾桶、茶叶筒、篮球、足球）；底部任务条「第 1 关 · 认识小伙伴 —— 点一下，实物变图形！」
- **交互**：点击任一实物 →
  1. 彩纸粒子在物品位置爆开（约 20 粒，四形状色）；
  2. 实物照片原地翻转缩小消失（0.35s）；
  3. 同位置弹出对应几何体（带笑脸），弹性放大落地（回弹 1.15→1.0），配 pop 音效；
  4. 已变身物品头顶打 ✔，不可再点。
- **收尾**：8 件全变完 → 所有图形自动列队居中排一行 → 头顶依次弹出名牌「长方体 · 正方体 · 圆柱 · 球」（间隔 0.5s，方便老师带读）→ 出现金色「下一关 ➜」按钮 + 提示"跟老师读一遍它们的名字吧！"
- **教师控制**：右下角小按钮「重来」（全部复原）。
- **判定**：无对错，纯探索，不扣分。

### 第 2 关 · 我说你猜（幕布猜一猜）

**教学意图**：课本 P21-23"摸一摸猜一猜"和 P30-33"猜猜我是谁"的舞台化，制造公开课高光。

- **进场画面**：中央粉色大幕布舞台（幕布下沿露出藏着的图形的小影子）；左侧「提示卡」区；右侧四个图形按钮（橙/蓝/绿/粉，粗描边大按钮）。
- **玩法流程**：
  1. 教师从左侧 4 张**预设谜语卡**点选一张（卡上即课本 P30-33 谜语原文，如"圆鼓鼓的小淘气，轻轻一推就滚走"），提示逐条显示在舞台上方；也支持**自己输入提示**（两个输入框，竞品同款）；
  2. 学生举手喊答案；
  3. 教师点右侧对应图形按钮 → 幕布升起（0.8s 缓动）→ 该图形从舞台弹出、翻跟头站定、头顶名牌 + 气泡「…说对了吗？」→ 全班鼓掌音效；
  4. 点「再来一轮」幕布落回，随机换下一个藏着的图形（不与上轮重复）。
- **另加「滚动大挑战」卡组**（课本 P23 原文线索）：「滚不动，可以推着走」「可以前后滚动」「可以任意滚动」三条线索逐条出，答案对应长方体/正方体、圆柱、球。
- **容错**：一年级不惩罚——点错图形按钮不扣分，幕布照样拉开，气泡改说"咦，是它吗？再看一眼它的面～"。
- **教师控制**：提示卡可编辑/清空；「直接揭晓」小按钮（学生实在猜不出时用）。

### 第 3 关 · 按形状分一分（把物品送回家）

**教学意图**：课本 P5「活动一：分一分」的竞赛化，红蓝两队轮流上台，全程最多学生参与。

- **进场画面**：上方并排 4 个"家"托盘（每家一个示例图形+名牌：长方体的家/正方体的家/圆柱的家/球的家）；中部散落 **16 件实物照片**（第 2.2 节映射表，随机打乱、不重叠）；右上进度牌「n/16 已经分好」；顶部队分板「🔴 红队 ★3 ｜ 🔵 蓝队 ★1」，当前轮到的队伍高亮呼吸动画。
- **玩法流程**：
  1. 当前队伍的学生上台，**拖动**一件实物到某个家上方松手；
  2. 判定形状：
     - **对** → 物品吸入托盘（缩小落座 + 弹跳），彩纸 + 对应提示语（每形状一句课本化表扬：长方体"对啦！长长方方站稳啦"；正方体"对啦！方方正正六面平"；圆柱"对啦！圆柱躺下能滚哦"；球"对啦！球滚滚球～"）+ 当前队 ★+1 + 音效；
     - **错** → 物品摇头弹回原位 + 鼓励语"再摸摸它的面，它到底是什么形状呢？"（不扣星）；
  3. 每放对 1 件自动换队（红→蓝→红…），顶部同步高亮；
  4. 16/16 全部分好 → 全屏彩纸 + 「送回家啦！」横幅 + 两队成绩展示。
- **教师控制**：「打乱重开」按钮（重洗 16 件换一批队上台）；拖拽全程支持触摸屏一体机（Pointer Events，同既有项目规范）。
- **异常处理**：物品拖到空白处松手 → 回原位不计错；同一物品不可重复拖（已入家的变半透明底图）。

### 第 4 关 · 小镇落成啦（成长小档案）

**教学意图**：课本 P36-38 收获总结 + 全班颁奖，公开课情绪收尾。

- **进场画面**：左侧「成长小档案」总结板；右侧空地舞台（竞品同款"小镇"）。
- **玩法流程**：
  1. 点「开始搭建」→ 前三关的图形积木**依次飞入空地**搭成小镇四个点位：小镇之家（长方体房身+正方体烟囱）、小镇广场（圆柱路灯+长方体长椅）、灯塔工坊（圆柱塔身+球顶）、球球乐园（一池彩球）——每个点位落下时弹出地名标签（0.4s 间隔，节奏感）；
  2. 总结板两句填空（课本 P36/P38 改编，可点选填入图形词）：
     - 「我发现生活中有些物体的形状是（　　）」——点词库填：长方体/正方体/圆柱/球
     - 「我会用几个相同的（　　）拼出新图形」——同上
  3. 点「全班颁奖」→ 按第 3 关两队星星数各颁一座奖杯（金/银可并列）+ 烟花 + 号角音效；
  4. 底部滚动字幕条播放课本 P37 顺口溜全文（教师带全班齐读，画面停留不自动跳转）。
- **教师控制**：「重放搭建」按钮。

## 5. PPT 整合方案（你最后的核心问题：游戏能不能放进 PPT）

**结论：能，三条路，推荐"A 保底 + B 增强"组合公开课使用。**（已搜索验证 + 实测你的站点）

### 方案 A：游戏按钮页跳转（100% 可行，零依赖，保底方案）

- PPT 在每个教学节点插入一页"游戏页"：整页放一个超大按钮图，设置**动作→超链接→本地 HTML 文件**；
- 点击后用 **Edge 应用模式**打开：`msedge --app="file:///C:/Users/aa109/Desktop/AIGame/小学一年级/认识立体图形-图形小镇.html"`——无边框无地址栏，观感像原生软件全屏，**Alt+Tab 一秒回 PPT**；
- 交付物：我给你 4 张即插即用的游戏按钮页（PNG + 设置好链接的页模板），外加一份《公开课跳转设置 3 步图解》。
- 优点：不联网、不装插件、任何电脑（包括学校旧一体机）都稳。

### 方案 B：Web Viewer 加载项真嵌入（游戏长在放映画面里，需联网）

- 搜索结论（知乎 / Microsoft Q&A 证实）：官方 **Web Viewer** 加载项只接受 **HTTPS 地址**且目标站允许 iframe；**本地 file:// 与局域网 http 都会被拒绝**；
- **实测**：你的 GitHub Pages 站点 `https://alejandron-1.github.io/AIGame/` 响应头**无 X-Frame-Options 限制 → 可以被 Web Viewer 嵌入**；
- 操作路径：PPT → 插入 → 获取加载项 → Web Viewer → 粘贴游戏 URL（如 `https://alejandron-1.github.io/AIGame/小学一年级/认识立体图形-图形小镇.html`）→ 游戏直接长在幻灯片里，放映时零切换；
- 风险与缓解：教室必须联网；首次加载慢（提前一页预载）；需登录微软账号装加载项（提前一天装好）。**上课电脑必须先实测一遍**；
- 兜底：同一台电脑同时准备方案 A，断网立刻切。

### 方案 C：整课 HTML 课件化（终极无缝，竞品的做法，建议二期）

- 把 38 页 PPT 的骨干页（情境图页、四个特征页、谜语页、儿歌页）做成**可翻页 HTML 课件**，四关卡游戏直接作为其中页面，方向键/翻页笔翻页，双击即用完全离线；
- 从此公开课全程只开一个文件，"不用切换"做到极致；工作量最大（≈ 新做一个项目），故列为二期。

### 方案 D：不推荐（踩坑记录）

- LiveWeb / ActiveX 浏览器控件：64 位新版 Office 兼容性差、需开宏，公开课当场崩溃风险高；
- 插入→对象 方式：只是图标跳转，不算嵌入，体验差。

## 6. 技术规格与规范

1. 单文件 HTML，UTF-8，中文分节注释；图片压至 ≤300px、WebP/JPEG、base64 内嵌，总量预算 ≤700KB（当前素材原图合计约 6MB，压缩比可控）；
2. 素材处理流水线（开发前置任务 M1）：黑底抠图（阈值法）→ 白底裁边 → 统一缩放 → **每张人工目检**（防止白边黑边）→ 16 件先给老师过目；
3. 交互一律 Pointer Events（教室触摸一体机 + 鼠标双端可用）；
4. 音效 Web Audio 合成，无外部资源；
5. 分辨率适配：教室一体机 16:9 全屏为主（1920/1280 基准），顺手做 ≤760px 手机断点（沿用全站规范）；
6. 状态纯内存，刷新即重置（公开课重开方便，无隐私数据）。
