## 一、竞品还原：四个环节（按截图逐图分析）

### 环节① 观察发现 —— 3D 情境图（图1、图2）

**竞品做法还原**：
- 一个可**拖拽旋转**的 3D 圆形舞台，上面摆放 **15 件生活物品**（篮球、足球、小皮球、魔方、黄积木、木箱、牙膏盒、木板、香皂盒、牛奶盒、电池、保温杯、罐头 等）
- 提示语：「拖一拖转一转 · 点一点认一认」——转动视角找物品，**点击物品**弹出身份卡
- 点击「电池」示例弹出：**「圆柱 · 电池」+ 特征描述**（"上下一样粗，两头是平平的圆，躺下来能滚动"）
- 右侧「我发现的形状」统计栏：**正方体 3件 / 长方体 6件 / 圆柱 3件 / ？共3件**——球的 3 件被"？"隐藏，**找到并点过才揭晓**（观察记录表）
- 15 件清单（按截图归纳，开发时可微调）：
  - 球×3：篮球⚽、足球、小皮球
  - 正方体×3：魔方、黄积木、木箱（方木箱）
  - 圆柱×3：电池、保温杯、罐头
  - 长方体×6：牙膏盒、木板、香皂盒、牛奶盒 等
  - 分类环节额外出现**圆锥类"另类"物品**：冰淇淋、三角积木（不属四类，进"另类桶"）

**教学价值**：转动视角=观察的完整性；点击揭晓=发现的仪式感；统计栏=观察任务的记录表。这一环节本身就是"导入+新授"。

### 环节② 分类命名 —— 拖拽分类 + 验证（图3、图4）

**竞品做法还原**：
- 顶部一排 16 张物品卡（15 件 + 冰淇淋圆锥），带「🔀 打乱顺序」按钮
- 指令①：把物品**拖进下面 4 个区域**——同一类放在一起；不属于的扔进「**另类桶**」
- 指令②：把「**模型图+名字**」小卡（正方体/长方体/圆柱/球）拖到区域头，**给区域命名**
- 底部：4 个虚线区域（？贴名字）+ 右侧「另类桶」
- 「**验证分类**」按钮：逐区域判定 → 正确区域绿框「**✓ 分对啦**」，错误区域红框「**再想想**」（如把香皂盒拖进"球"区域 → 红框提示）
- 「重新整理」按钮重置
- 字幕提示：分类环节有多种操作方案（如先给区域命名）；玩法多样，手指拖动即可

**分析**：这是"分类与整理"标准+图形识别的复合活动。两种教学路径都支持：先命名后分类（演绎）或先分类后命名（归纳）——**都应保留，由老师自由决定顺序**。

### 环节③ 动手拼搭 —— 拖零件拼结构（图5、6、7、8 + 图9）

**竞品做法还原**：三个子关卡
- **拼一拼：圆柱小凳**：把 **4 个圆柱**拖到桌面下方的**光圈**里（吸附），拼成一张小凳子；已放 0/4 计数；点已放好的零件可以取下；全部放好 → 长方体桌面**落下**盖在圆柱腿上 → 拼搭成功语："小凳搭好啦！圆柱上下是平平的圆面，立起来稳稳的！"
- **拼一拼：方柱小凳**：同结构用长方体/正方体组合（"还可以试试长方体组合"）
- **玩一玩：会滚的平板车**（图9）：在平板下面放 **3 个圆柱"轮子"**，装好后出现「**滚一滚！**」按钮 → 平板车**滚动前进**；题面追问"**试试长方体行不行？**"——把长方体装上当轮子，滚不动/颠簸 → **"圆柱躺倒能滚，长方体滚不了"的特征对比**在此具象化（字幕："经典搭配，可以制造滚轮、搬运工具"）

**分析**：这是全课件的高光环节——把"特征认知"升级为"特征应用+反例验证"。圆柱能滚、长方体不能滚的对比是本环节的灵魂。

### 环节④ PK练习 —— 双人判断对战（图10、11、12）★截图补充完整

**竞品做法还原**：
- 顶栏控制：**第 N 轮**显示、「**下一轮**」按钮、「**清空比分**」按钮
- 规则原文：「倒计时后两边同时出现物品，谁先点对它的名字（正方体/长方体/圆柱/球）谁得分；**点错不扣分**，答正即可，**但时间还在走**哦！」
- 双面板：**蓝莓队**（蓝头）vs **橙子队**（橙头），中间红色 "VS"；各队面板 = 小圆台托一件 3D 物品（**两队物品各自独立随机**，如罐头 vs 黄积木、保温杯 vs 牛奶盒）
- 流程：倒计时（3-2-1）→ 物品同时亮相 → 两队各自点四选一按钮（正方体/长方体/圆柱/球，带彩色圆点）
- 判定：各自答对后显示「✓ 答对啦！用时 X.XX 秒」（精确到 0.01 秒）；**本轮获胜 = 先答对者**，获胜方弹「🏆 本轮获胜！」徽章并得 ⭐（星标显示在队头）
- 每轮答完自动/点击「下一轮」换新物品继续；比分累计，可清空
- 每轮结束后字幕呼应特征：「陆续分享立体图形的特征，与前面呼应，增强概念理解」（如答完罐头弹一句圆柱特征）

**分析**：同题独立答 + 计时不扣分的赛制非常适合一年级——比的是"准"和"快"，错不打击但会输在时间，天然鼓励学生想清楚再按。物品两队**不同**（各自随机），防抄答案。

## 三、技术方案建议

1. **单文件 HTML 零依赖**（项目规范）；伪 3D 用 DOM+CSS transform 实现（物品 billboard + 椭圆轨道 + depth 排序），60FPS 无压力
2. 触屏 Pointer Events + 300ms 防抖；物品点击热区 ≥44px
3. 音效 Web Audio 合成：破壳式"咔嚓"（拆）、"叮"（配对）、胜利琶音
4. 主题配色参考竞品：米白底 + 黑板绿描边 + 橙黄强调（公开课黑板风，与项目其他游戏区分开）
5. 手机适配：≤760px 单列（观察发现舞台在上、统计栏在下；分类区域 2×2；拼搭全宽）
