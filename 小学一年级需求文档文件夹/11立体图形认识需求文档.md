# 《立体图形认识》需求文档 V1.0 —— 生活物品版 · 教师可自定义图库

> 适用：一年级 认识图形（立体）：球、正方体、长方体、圆柱（+平面图形长方形/正方形/圆/三角形 可后续扩展）
> 形态：单文件 HTML（`小学一年级/立体图形认识.html`），零依赖离线可用
> 来源：教师需求——**用生活中的物品教立体图形**，且支持教师**自己拍摄物品照片、自己标注名称与形状**，在游戏中展示给学生

------

## 一、对"示例界面 + 自定义图库"的整体设计

三个页签（一年级零文字门槛，全图标导航）：

```
📖 学一学（示例界面）   👜 我的物品（教师编辑器）   🎮 考一考（游戏）
```

### 1. 📖 学一学（示例界面）
- 按 4 种立体图形分组展示生活物品：**球**（⚽🏀🍉）、**正方体**（🎲🧊）、**长方体**（📚📦🧱）、**圆柱**（🥫🔋🥤）
- 每个物品卡片：大图案 + 物品名 + 形状徽章；点击看大图与一句特征口诀（"圆圆滚滚，四面八方都能滚——是球"）
- 目的：给教师一段"指认教学"时间，学生先建立"实物→图形名"的映射

### 2. 👜 我的物品（教师编辑器）★核心
- **上传**：拍照/相册图片（自动压缩到最长边 800px、JPEG，省存储）
- **标注**：物品名称（如"爸爸的保温杯"）+ 选择形状（球/正方体/长方体/圆柱）
- 列表管理：缩略图 + 名称 + 形状徽章 + 删除
- 存储：localStorage（key `shape3d_items`），上限 60 件（超出提示删除旧的）
- 自定义物品**自动进入考一考题库**，与内置物品混出

### 3. 🎮 考一考（游戏）
- 设置：题目数量（5~20，默认 10）
- 每题：随机展示一个物品（大图）→ 四个形状按钮（球/正方体/长方体/圆柱，正确项+3干扰）→ 点选
- 答对：烟花 + 音效 + 下一题；答错：摇晃 + 正确项闪烁提示，可重选（不限次）
- 全部完成：结算（答对/用时），撒花庆祝

------

## 二、出题与判定规则

1. 干扰项 = 其余 3 种形状（4 种形状全展示，无重复）
2. 自定义物品存在时：题目池 = 全部内置 + 全部自定义；自定义物品出现概率加权 ×2（自己拍的孩子更熟，多练）
3. 同一轮不连续出现同一物品
4. 物品池不足 4 种形状覆盖时不影响出题（形状选项固定 4 种，与物品无关）

------

## 三、边界与异常

1. 上传非图片/损坏文件 → toast 提示重试
2. 存储满 → 提示删除旧物品
3. 未上传任何自定义物品时"考一考"用内置物品正常游玩（不空转）
4. 刷新不丢自定义物品（localStorage 持久）；「清空我的物品」需二次确认

------

## 四、视觉与交互

- 糖果渐变风延续；物品大图、按钮大（触屏友好）
- 手机适配：卡片网格 auto-fill 自适应，单列可用（本游戏按手机可用标准开发，作为全站手机适配的样板）
- 音效：答对上行音、答错柔和音、通关胜利音（Web Audio 合成）
