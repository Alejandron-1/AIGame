# 19 3D口算卡（翻页式口算练习）

来源：小红书「一上数学10以内加减法 | 3D口算题卡」（橘老师）的模仿改造。原封面是版权插画，本项目按惯例**手绘原创 SVG 艺术封面**（梨形夜空摘星主题，呼应原作意境不照搬）。

## 教学目标

- 一年级上册 10 以内加减法口算熟练度；替代纸质口算卡，省去手写。

## 玩法流程（对应视频）

1. **封面**：薄荷桌垫上放着一本艺术封面口算本（铅笔、橡皮、太阳、星星涂鸦），点击封面 → 3D 翻页打开本子。
2. **扉页**：右侧页显示「一年级·口算卡片 / 10以内的加减法 / 0～9加减法·N道 / 答对自动翻一张」，底部小设置（题数 5/10/15/20 · 加法/减法/混合）。点击扉页翻页开始。
3. **答题**：右页大字算式「8 − 2 = ▢」，桌上数字键盘（1-9、0、退格、确定）输入；
   - 答对：答案框变绿 + ✓章盖上 + 小星光 → 自动翻一张；
   - 答错：卡片抖动、答案框变红清空、可重答（计入答错次数）；
   - 左页淡淡记录已答题目（✓/✗），页边累积翻页厚度。
4. **收尾**：最后一题答完 → **连续快速翻页动画**（一叠空白页哗哗翻过）→ 成绩卡：「全部答完 / 用时 mm:ss · 答错 n 次 · 正确率 p%」，按钮「错题重做」「再来一轮」。

## 出题规则（学科红线：一年级 10 以内）

- 加法 a+b≤10（a,b≥0），减法 a−b（1≤a≤10，0≤b≤a）；整副去重洗牌。
- 答案可能为两位数 10，键盘支持两位输入。

## 约定

- **无音频**（沿用用户最新要求）。
- 翻页用 CSS 3D：book 容器 perspective，叶子 transform-origin 左脊 rotateY(-180°)，状态推进用固定 setTimeout（FLIP_MS）驱动，不依赖 transitionend。
- 测试钩子 `window.__T`；截图参数 `?demo=1`（直达答题）、`&right=1`（答对态）、`&score=1`（成绩页）、`&still=1`（禁动画看布局）。
- 注册 index.html 一年级区。
