## 一、项目概述

* **项目名称**：数字列车 6~10（交互课堂课件）
* **目标用户**：小学一年级学生（新一上）或幼小衔接儿童。
* **核心目标**：掌握 6~10 的数量对应、数序认知、基数与序数（第几）概念。
* **终端平台**：**以 1920×1080 教室交互大屏为唯一基准**，1280×720 可用；不支持手机竖屏（与项目既有 15 款游戏一致，不做响应式）。
* **视觉风格**：明亮卡通风（蓝天草地 + 白色圆角卡片），元素大而清晰，最远 8 米可读；正文最小字号 20px，关键数字 ≥72px。
* **交付物**：单文件 `小学一年级/数字列车.html`，零外部依赖，双击即用。
* **明确不做（V2 备选）**：麦克风语音识别答题。本版"AI 交互"体现为语音播报 + 智能支架提示，不做 ASR。

## 二、界面布局与全局逻辑

### 2.1 界面布局

```
┌────────────────────────────────────────────────────────────────────┐
│ ← 返回目录   数字列车 6~10   [①数量与数字][②尺子上的数][③第几节车厢]   🔊声音  ⏭下一题  🔄重来 │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│                        主内容区（占屏 ≥80%，按关卡渲染）                │
│                                                                    │
├────────────────────────────────────────────────────────────────────┤
│ 💬 任务提示（≥28px）  🔊重听      🚂 进度：●●●○○  3/5                  │
└────────────────────────────────────────────────────────────────────┘
```

* **顶部导航**：`← 返回目录`（指向 `../index.html`）、标题、三关 Tab、`🔊 声音`（同时控制音效与语音，默认开）、`⏭ 下一题`（常驻，老师可随时跳题）、`🔄 重来`（重置当前关卡，题号与进度归零）。
* **底部提示区**：任务指令文字 + `🔊 重听`（重复朗读当前指令）+ 进度指示。
* **进度指示（主题化）**：🚂 + 5 个车厢格，每答对 1 题挂 1 节；5 节集齐后小火车鸣笛从左跑到右。
* **v1.0 的"刷新按钮"** 落定为顶部 `🔄 重来`（v1 前后文矛盾，此处统一）。

### 2.2 全局交互逻辑（已定稿）

| 项 | 规则 |
|---|---|
| 题量 | **每关 5 题一轮**，答完全部 5 题进入"通关庆祝" |
| 题目推进 | 答对后 **延迟 1.2 秒自动**进入下一题；`⏭ 下一题` 可随时手动跳过（跳过不计进度、不计对错） |
| Tab 切换 | **保留各关自己的进度与当前题**；只有 `🔄 重来` 才重置当前关卡 |
| 重置 | `🔄 重来` = 进度归零、重新出题 |
| 语音引导 | 每题刷新、切换关卡时**自动朗读指令**；`🔊 重听` 可重复朗读；声音关闭时全部静音（含语音） |
| 正确反馈 | 元素放大 1.15 倍 + 绿色高亮 + 上行三音"叮" + 表扬语（"太棒了！""真准！""数得真好！"随机） |
| 错误反馈 | 元素左右摇晃 0.4s + 低沉下行提示音 + 温和提示语；**不扣分、无红叉**，可无限重试 |
| 防误触 | **同一元素** 300ms 内重复点击忽略；不同元素的多点触控正常放行 |
| 出题约束 | 同一轮 5 题内不重复同一道题（同数量/同隐藏数字/同车厢不连续出现） |
| 数据 | 不写 localStorage，刷新即重置（符合项目"防课堂公用电脑脏数据"原则） |
| 隐藏控制台 | `空格`=下一题、`R`=重来本关、`A`=显示答案、`Esc`=返回目录；首次进入关卡时提示一次，之后不再提示 |

## 三、核心关卡详细规格

### 关卡一：数量与数字

**教学目标**：手口一致点数，建立"数量 ↔ 抽象数字"的对应。

| 规格项 | 定稿值 |
|---|---|
| 物体数量 | **6~10（含两端）**随机 |
| 物体种类 | 5 种图形池：向日葵 / 苹果 / 小鱼 / 星星 / 气球；**每题随机一种，整题统一** |
| 物体排布 | 每行 5 个，超出换行（6~10 个 → 2 行） |
| 点子圆圈 | **固定 5+5 两排共 10 个**虚线圆；点击点亮（填充 + 显示序号 1、2、3…），**可再次点击取消**，取消后序号自动重排 |
| 报数反馈 | 每次点亮：音高随序号递增的"叮" + 圆内显示序号；另有 `清空` 小按钮 |
| 通关条件 | ① 点亮数 = 物体数 **且** ② 所选数字 = 物体数（**两个条件在点数字时一并判定**） |
| 交互顺序 | **点子可自由增减、数字按钮始终可点**，点错可改、点多了可取消，点数字时才判对错。<br>※ 开发中修正（2026-09-12）：原设计"点亮数一到位就锁定并提示'数对啦'"实测存在**暴力试探漏洞**——孩子只要一格一格点下去，点到提示"数对啦"就能拿到答案，点数环节被完全绕过。故改为不锁定、不提前判定；答对后整排点子与数字按钮一起变绿高亮。 |
| 数字选项 | **4 个 = 正确答案 + 3 个干扰项**；干扰项取自答案 ±1、±2（限定 1~10、去重、不含答案），最后整体打乱 |
| 过程提示语 | 分两段，**完整引导语每题只出现一次**：<br>① 进入本题 → `上面有几个？点亮同样多的点子，再选出数字`（同时语音朗读一次）<br>② 开始点任意一个点子后 → 只显示进度 `已点亮 3 个`（不再重复整句，避免刷屏）<br>※ 全程 **绝不显示目标数量**（2026-09-12 调整：原设计每次点击都重刷整句引导语，一道题内重复十余次，故拆分为"引导语 + 进度"两段） |
| 支架提示 | 同一题内"点亮超过目标数"、"点清空"或"数字选错"累计 **3 次**后，才显示 `悄悄提示：一共要点 7 个点子` 并语音读出 |
| 答对反馈 | 所选数字变绿放大 + 整排点子转绿 + 上行三音 + 表扬语 + 进度挂 1 节车厢；1.2s 自动下一题 |
| 答错处理（分级提示，均不揭示答案） | ① 数字对、点子不对 → `数字选对啦！再数一数，点亮同样多的点子`；② 点子对、数字错 → `点子点对啦！再想想，是数字几呢？`；③ 都不对 → `再数一数，到底是几呢？`（按钮摇晃 + 低沉音，可无限重试） |

### 关卡二：尺子上的数

**教学目标**：认识 0~10 数序，理解相邻数关系。

| 规格项 | 定稿值 |
|---|---|
| 尺子 | SVG 绘制，刻度 0~10 **共 11 格**，数字标在刻度下方，等宽 |
| 隐藏范围 | **1~9**（避开 0 和 10 端点，避免端点题歧义）；同轮不重复 |
| 遮盖 | 黄色方块盖住该数字（含刻度），带高亮描边 |
| 候选按钮 | **5 个 = 正确数 ±2 滑动窗口**（越界向内补邻，如隐藏 1 → {1,2,3,4,5}；隐藏 9 → {5,6,7,8,9}），必含正确答案，打乱顺序 |
| 提示语 | `尺子上缺少哪个数？` |
| 正确反馈 | 数字从按钮**飞入**方块位置，方块爆开消失，尺子恢复完整；语音 `尺子的数排好啦，6 回来了`；1.2s 后下一题 |
| 错误反馈 | 按钮摇晃 + 语音 `再想一想，它的前面是 5，后面是 7` |
| 支架提示 | 同一题错 3 次 → 高亮左右邻居并加箭头 `前面是 5 · 后面是 7` |

### 关卡三：第几节车厢

**教学目标**：区分"几个"（基数）与"第几"（序数），练习从左往右、从右往左数。

| 规格项 | 定稿值 |
|---|---|
| 火车 | **车头固定在左**，其后 10 节车厢从左到右排列（第 1 节紧挨车头） |
| 车厢编号 | **★易：车厢印 1~10；★★难：车厢不印编号**（只有车窗，需自己数格子） |
| 难度切换 | 默认★易；**连续答对 3 题自动升★★**并提示 `升级啦！车厢上的数字藏起来咯`；答错 2 次退回★易 |
| 方向指示 | 轨道上方虚线 + 箭头 + 文字，统一表述：`从左边数 →` / `← 从右边数`（v1.0 的"左边 →"含糊表述废弃）；朗读一律"从左边数/从右边数" |
| 指令 | `从右边数，第 6 节车厢——是哪一节？`（v1.0"第6只表示这一节"病句废弃） |
| 随机范围 | 方向随机（左/右各 50%）；**节次限定 1~8**（避开贴边的 9/10） |
| 目标算法 | 从左数：目标编号 = 节次；从右数：目标编号 = 11 − 节次（即 v1.0 的 `10 − n + 1`，一致） |
| 正确反馈 | 该车厢变绿 + 跳动；★★难时同时**揭示该车厢编号**；语音 `答对啦！从右边数，第 6 节就是它` |
| 错误反馈 | 该车厢摇晃（回复原色） + 语音 `从右边开始数：1、2、3……再试试` |
| 支架提示 | 同一题错 3 次 → 从正确方向**逐格亮起计数箭头**（0.35s/格）走到目标车厢，并显示 `一共点出了 6 节` |

## 四、技术与非功能性需求（定稿）

1. **渲染**：图形全部内联 SVG（模板字符串 / `createElementNS`），矢量缩放不失真；文字与按钮用 DOM + CSS。
2. **音效（P0，必做）**：全部 **Web Audio API 程序合成**，不引入任何音频文件 —— 正确=上行三音（C6-E6-G6）、错误=下行两音（A3-F3 方波）、点击=短促木鱼音、报数=随序号升高音高、通关=四音号角。
3. **语音（P0）**：**Web Speech API（`zh-CN`，rate 0.85）** 朗读指令与表扬语；不可用或无声时**静默降级**为屏幕大字 + 音效，不报错、不弹窗。预留 `audio/` 目录，后续可整体替换为预录配音。
4. **动画性能**：动画只用 `transform` / `opacity`，目标 60FPS；单次动画 ≤0.6s（通关庆祝除外）。
5. **离线可用**：单文件、零网络请求（含零 CDN），断网可完整运行。
6. **适配**：不做移动端；尺寸用 `clamp()` + `vw` 随大屏缩放，1920×1080 无滚动条。
7. **容错**：所有音频/语音调用包 `try/catch`，任何失败不影响游戏流程。
8. **可维护**：中文注释标注三关渲染入口与参数区（`CONFIG`），便于后续自行改数值。
