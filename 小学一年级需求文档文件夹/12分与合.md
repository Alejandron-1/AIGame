# 《分与合》需求文档 V2.0 —— 小球分家 · 数的分解与组成

> **适用**：一年级上册 第三单元「1~5的认识和加减法」、第五单元「6~10的认识和加减法」中的"分与合"
> **形态**：单文件 HTML（`小学一年级/分与合.html`），CSS/JS 全内联，零依赖、断网双击可用，以 1920×1080 教室大屏为基准
> **来源**：依据教师提供的 3 张课堂截图（标题"新版—上AI交互 · 分与合"）还原界面与玩法，并补全截图中未定义的数值与规则
> **定位**：**计算教学的算理起点**。项目现有口算三兄弟（数学拔河 / 数学赛车 / 飞驰人生）练的是"算得数"，凑十对对碰、破十训练营练的是"算的策略"，唯独缺"数可以怎么拆"这一层。对照《09覆盖盘点与补充规划（第三批）》的覆盖矩阵，上册第 3、5 单元标注为"✅ 口算三兄弟"，但口算只覆盖了加减法计算，**"分与合"作为这两个单元的第一课时（加减法的算理基础）始终没有独立载体**——本作填补该空白。

**V1.1 变更（2026-09-19，教师确认）**
1. 数字**控制在十以内**（2~10，硬上限不变）
2. 顶栏**增加 `⚙ 设置` 项**，可设置参与游戏的**数字范围**（对应"先练 5 以内、再练 10 以内"的教学进度），详见第八节

**V2.0 变更（2026-09-20，课堂反馈"bug 太多"后推倒重写）**
1. **交互简化**：删掉 V1 的"点球选中 → 再点方向"中间态（选球状态与取球点击互相打架，孩子点球没反应）。还原截图原始交互——**点「放到左边 / 放到右边」，待分配区第一颗球直接飞过去；点房间里的球取回**，仅此两条路径
2. **「重新分」后结论句和记录都保留**（截图 3 实证：房间 0/0 时结论句仍显示"4可以分成2和2"——V1 错误地把它复位回了"试一试"）
3. **`⚙ 设置` 改范围不再误清进度**：当前数字仍在范围内时进度一点不动（V1 只要碰设置就全部重来）；越界才跳新范围下限重开
4. **修复闪屏**：V1 每次发现新分法会把整排记录卡片重新播一遍动画，V2 只给最新一张加弹入动画
5. **修复竞态**：找齐庆祝延时 650ms 触发，期间若重新分/取球，庆祝照样弹出——V2 引入"状态代数戳"，任何重置都让过期定时器自动作废（支架提示同理）

## 一、教学目标（一节课要带走的三件事）

| # | 目标 | 在游戏里怎么达成 |
|---|---|---|
| T1 | **会分**：把 N 个物体分成两部分，说出"N 可以分成 a 和 b" | 亲手把小球逐个分进两个房间，分合式同步显示两个部分 |
| T2 | **会合**：反向说出"a 和 b 组成 N" | 分完一种，界面同时给出正反两句话并语音朗读 |
| T3 | **有序思考**：不重复、不遗漏地找出 N 的**全部分法** | 「已经发现的分法」记录区只显示已找到的，用进度 `已找到 2/4` 制造"还差几种"的目标感 |

> T3 是本作最不可替代的价值。一年级"分与合"的考点从来不是"5 能分成几和几"，而是**能不能有序地一个不漏**。本作把这件事从"老师板书列一遍"变成"学生自己凑齐一套"。

## 三、主玩法：分一分（自由探索，截图核心）

### 3.1 把小球放进房间（V2.0：只有两条交互路径，无选球中间态）

| 路径 | 操作 | 说明 |
|---|---|---|
| **放球** | 点 `放到左边` / `放到右边` → 待分配区**第一颗**球飞入对应房间 | 一次一颗，无需先选球。截图 2：孩子直接指方向按钮，左堆 3、顶上剩 2，即此交互 |
| **取回** | 点房间里的任意小球 → 取回待分配区末尾 | 截图 2 实证：左 3 / 右 0 / 顶上 2 的状态只能由"分完 (3,2) 记录后逐颗取回右堆"产生，说明原版支持逐颗取回 |

> V1.1 的"点球选中 → 点方向"两条路径方案已废弃：选球高亮、点房间球取回、点待分配球切换选中三个行为挤在一起，课堂上表现为"点了没反应 / 球乱跳"，是本次重写的直接原因。

- **重新分**：所有球回到待分配区，两个房间归 0；**结论句与「已经发现的分法」记录都保留**（截图 3 实证，见 V2.0 变更第 2 条）；"卡住计数"同样不清零（见第五节 D1）
- 球全部放完后 `放到左边`/`放到右边` 置灰不可点

### 3.2 分合式实时联动

- 上方固定显示总数 `N`
- 下方两个方框**实时**显示当前左堆、右堆的球数（与房间内数字同源，一并更新）
- 两个方框在**未分完**时保持灰色弱化样式，**分完后**变为实心高亮（绿底白字）

### 3.3 什么算"一种分法"（关键判定）

> **判定条件（两个都要满足）**：① 待分配区已空（N 个球全部放完）；② 左堆 ≥ 1 **且** 右堆 ≥ 1。

- 把球全丢到一边、另一边留 `0` 的，**不算一种分法**，提示条温和提示：`两个房间都要有小球哦`（截图 1、截图 3 里 0/0 是**起始态**，截图 2 中 3/0 是**中间态**，均不记为分法）
- 记为分法时按**有序对 (左, 右)** 去重：`5 分成 1 和 4` 与 `5 分成 4 和 1` 是**两种不同分法**（人教版教材正是成对呈现，交换即另一种）
- 因此 **N 的全部分法数 = N − 1 种**（N=2 时 1 种，N=5 时 4 种，N=10 时 9 种）

### 3.4 反馈分支

| 情况 | 分合式下方文字 | 记录区 | 音效 |
|---|---|---|---|
| 未分完（初始态） | `试一试不同的分法。` | 不变 | — |
| 分出**新**分法 | `5 可以分成 3 和 2。` + `3 和 2 组成 5。`（两行同时出现）+ 语音朗读 | **新增**一张分法卡片，进度 +1 | 「叮」上行音 + 球落定「啵」声 |
| 分出**重复**分法（已在记录中） | 保持现状 | 不新增，不扣分 | 柔和低音（**不惩罚、不报错**） |
| 全部分法**找齐** | `太棒了！5 的 4 种分法全部找到啦！` | 记录区整体高亮 + 卡片按左数从小到大重排 | 欢呼音 + 撒花动画 |

## 四、"已经发现的分法"记录区

- 标题右侧显示进度：`已找到 2 / 4`
- 每发现一种，新增一张**迷你分合式卡片**（缩小版：上 `5`、下 `3` `2`），卡片带轻微弹出动画
- **未发现的分法不显示任何数字**（绝不泄题），仅以进度数字给出"还差几种"的目标感
- 找齐后，所有卡片按**左数从小到大**重新排列——让学生一眼看见"1和4、2和3、3和2、4和1"这整齐的一串，这正是"有序"的视觉化
- 换一个数时记录区清空重算（每个数各有一套记录）

## 五、支架提示（卡住才给，绝不提前泄题）

触发条件（满足其一）：

| 触发 | 提示内容 |
|---|---|
| 同一总数内，**连续 3 次**分出的都是已找到过的分法 | 提示条：`按顺序试一试：从 1 和几开始，再 2 和几，一个都不漏哦`（**只给方法，不给任何具体数字**） |
| 同一总数内，**连续 3 次**把球全放在同一边 | 提示条：`两个房间都要有小球哦，先放 1 个到左边试试` |

- 提示每次出现均配语音朗读，且同一数内只触发一次
- **任何情况下都不直接说出剩余分法的具体数字**（对照《09数学列车》D1 教训：绝对避免"一直试就能拿到答案"的漏洞）

> **D1（开发实测发现并已修正）**：`重新分` 只把球归位，**不清空"卡住计数"**。原因是学生每试完一种分法都必须点「重新分」才能再试，如果把连续重复的计数一起清零，判定就永远到不了 3 次，支架提示形同虚设——这个缺陷是写完代码做逻辑回归时被断言抓出来的。卡住计数只在**换一个数字**时归零。

## 六、参数与数值（全部拍死，开发直接照此实现）

| 项 | 取值 |
|---|---|
| 总数 N 硬上限 | **2 ~ 10**（十以内，1 无分法不出现）；实际参与范围由教师在 `⚙ 设置` 里限定 |
| 初始 N | **5**（与截图一致）；若教师设置的范围不含 5，则取范围上限 |
| `换成 N 个` 按钮 | 按钮文字 = **下一个总数**（当前数 − 1，减到范围下限后回到范围上限继续递减）→ 点击后 N 变为该值。初始 N=5、范围 2~10 时按钮显示"换成 4 个"，与截图完全一致 |
| 数字快捷切换 | 在 `⚙ 设置` 面板里，可直接点选范围内的任意数字跳转 |
| 一轮题量 | **无固定题量**，探索模式按"数"推进，每个数找齐全部分法即完成 |
| 是否计分 | **不计分、不排名**；学生游戏进度不写 localStorage，刷新即重置 |
| 设置持久化 | **仅**教师的范围设置写入 `localStorage['fenhe_settings']`（老师不必每次重设），学生进度仍不持久化 |
| 球直径 | 待分配区 `clamp(38px, 3.4vw, 66px)`；房间内 `clamp(26px, 2.3vw, 46px)` |
| 自动跳转 | **不自动**跳下一个数。找齐后停留在当前数，由老师点"换成 N 个"推进（课堂节奏交给老师，避免投影时被打断） |
| 300ms 防抖 | **仅作用于同一元素**，不同元素的多点触控放行（大屏多人操作） |

## 七、视觉与音效

**视觉**
- 整体浅蓝灰底（还原截图色调），白色/浅色半透明面板，大圆角，高对比度
- 小球：橙红色径向渐变 + 左上白色高光 + 中心一个深色小孔（还原截图中"带眼的小球"造型），纯 CSS 绘制
- 房间框：浅色半透明 + 虚线描边；球飞入时用 CSS transition 走一段抛物线
- 分合式线条为深色，粗细适中；数字为深色加粗
- 层次遵循"①球 ②房间数字 ③分合式"由大到小，保证最后一排学生也能看清

**音效（Web Audio 程序合成，零音频文件）**
| 事件 | 音效 |
|---|---|
| 球飞入房间 | 短促「啵」 |
| 发现新分法 | 上行双音「叮咚」 |
| 重复分法 | 柔和低音（**不刺耳、不报错感**） |
| 全部找齐 | 欢呼音 + 撒花 |

**语音（Web Speech API，`zh-CN`，rate≈0.85）**
- 分完一种：朗读 `5 可以分成 3 和 2，3 和 2 组成 5`
- 找齐：朗读 `太棒了！5 的 4 种分法都找到啦`
- 支架提示出现时同步朗读
- `🔊 声音` 关闭时音效与语音**同时**静音；API 不可用时静默降级，全部包 `try/catch`

## 八、教师设置与快捷键（V1.1 重点）

### 8.1 `⚙ 设置` 面板

顶栏 `⚙ 设置` 按钮打开居中弹窗，含三项：

| 项 | 控件 | 说明 |
|---|---|---|
| **数字范围** | 两个下拉：`最小 2~9` ～ `最大 3~10` | 限定参与游戏的总数区间，硬上限 10。选好后立即生效并记住 |
| **快捷预设** | 三个按钮 `2~5` / `6~10` / `2~10` | 依次对应上册第三单元（5 以内）、第五单元（6~10）、全册复习 |
| **当前数字** | 范围内每个数字一个按钮，当前数高亮 | 老师可直接跳到某个数，不必反复点 `换成 N 个` |

规则：
- 范围改变后，若当前 N **仍在范围内 → 进度、结论、记录一律不动**（V1 只要碰设置就全部重来，课堂上误碰即前功尽弃）；不在范围内则自动取**新范围的下限**重开（由易到难）
- 设置写入 `localStorage['fenhe_settings']`，下次打开仍是老师的配置；**学生游戏进度不持久化**
- 弹窗打开时暂停响应游戏操作；点「完成」或按 `Esc` 关闭
- 任何时候 `最小` 必须小于 `最大`；下拉选项自动互斥

### 8.2 快捷键

| 快捷键 | 功能 |
|---|---|
| `空格` | 换成下一个数（等同点 `换成 N 个`） |
| `R` | 重新分（球归位，记录保留） |
| `A` | 显示剩余答案（把未找到的分法一次性填入记录区，**教学讲解用**） |
| `T` | 打开/关闭 `⚙ 设置` |
| `Esc` | 有弹窗时先关弹窗；无弹窗时返回目录 |

## 九、边界与异常

1. N=2 时只有 1 种分法（1 和 1），找齐文案自动适配为"N 的 1 种分法"
2. 球全部放入一个房间、另一房间为 0 → 不算分法，仅温和提示，可继续操作
3. 记录区卡片数量多（N=10 时 9 张）→ 卡片自动缩小并换行
4. 设置里的"最小"若等于或大于"最大"，自动纠正为合法区间
5. 切到其他页面再回来 → 学生进度重置（设置项保留）
6. 语音/音频 API 不可用 → 全部静默降级，游戏逻辑不受影响
7. 断网双击文件可完整游玩，无任何外部请求
