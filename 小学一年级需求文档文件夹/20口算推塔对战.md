# 20 口算推塔对战（看图列式+连加连减）

来源：小红书「橘老师·看图列式+连加连减推塔课件」+《战争进化史》式出兵攻塔动画（用户想要的加强版：答对不出"推塔特效"而是**出兵走过战场砍塔**）。

## 教学目标

- 一年级上册两大难：看图列式（加减由学生自己判断）+ 连加连减（按顺序算）。全班分红蓝两队抢答巩固。

## 规则（对应橘老师三条 · 2026-11-24 与老师确认的终版）

1. 大屏左右各一座主塔（血量 100，分 5 层），全班分红队/蓝队，各答各的题。
2. **答对的队出兵**：小兵从己方基地走过战场，到对面塔下挥剑砍 3 下，**每次答对总伤 51（6+6+5）——答对 6 次推平一座塔**；推光对面塔立即获胜。
3. 一局 2 分钟倒计时（可选 3 分钟）；铃响时正在答的题算"最后一题"，给 8 秒加时答完。时间到未推平 → 塔剩余血多者胜，血相等平局。
4. 答错不扣塔：面板抖动红框，可重答（保护积极性，对应橘老师小经验）。

## 判定规则记录（⚠ 老师若要改"什么算对"，只改这一表 + 回归测试）

> 2026-11-24 与老师确认。代码中集中在 `judgeEquation()` 一个函数，此表为唯一口径。

| 题型 | 标准判对 | 额外判对（宽容） | 判错样例 |
|---|---|---|---|
| ① 看图求总数 | `a+b=res`，运算符必须 `+` | 无 | 用减法、结果错 |
| ② 看图求另一部分 | `total−cut=res`，`−` | **想加算减**：`cut+res=total` 或 `res+cut=total`，`+` | 结果错 |
| ③ 连加 | `a+b+c=res`，两个 `+` | 无 | 运算符/数错 |
| ④ 连减 | `t−b1−b2=res`，两个 `−` | **无**（不留加法宽容，防歧义） | 混用加法 |
| ⑤ 纯算式 | 同 ③/④（无图） | 同上 | 同上 |

**连减图固定画法（防歧义）**：总数（不划）在前 → 划掉的组紧随在后（红线），总数组下方标「共 N 只」；求另一部分同理标「共 N 只」。
**后续若老师要改判定口径**：只动 `judgeEquation()` + 此表 + 对应测试断言。

## 出题（10 以内）

- 题型池（设置可选：看图列式 / 连加连减 / 混合，默认混合）：
  - 求总数：两组 emoji，▢+▢=▢（运算符由学生判断）
  - 求另一部分：总数+划掉一部分，▢−▢=▢
  - 连加：三组图 ▢+▢+▢=▢
  - 连减：总数在前不划 + 两组划掉，▢−▢−▢=▢
  - 纯算式：无图直接算式
- 所有数 ≤10，减法不出负数，连加和 ≤10；红蓝两队题目不同。

## 交互（点数字即作答，与 3D 口算卡统一）

- 点数字→填入第一个空槽（已点选的槽直接替换；1 后按 0 拼成 10）；`＋/－` 填运算槽（点运算槽可改）；退格删。
- **无确定键**：填满最后一个数自动判定（此前确定键会把 'ok' 塞进答案槽，已移除）。

## 动画要点（难点拆解）——已升级为真 3D

- **3D 战场**（2026-11-22 升级）：three.js（项目共享 `小学一年级/three.min.js` r128）+ `GLTFLoader.js`/`SkeletonUtils.js`（r128 examples，随库存放）+ `推塔素材/Soldier.glb.js`（three.js 官方示例 Soldier 模型 base64 内嵌，MIT 许可；转 base64 是为规避 file:// 下 GLTFLoader 的 CORS 限制，classic script 不受此限）。
- 透视相机俯视战场，PerspectiveCamera + HemisphereLight + 平行光投影；地面/道路/低模树/飘云全程序化建模（Kenney 风格 flatShading）。
- **出兵**：答对后 SkeletonUtils.clone 士兵，播 Walk 骨骼动画，1.7s 走到对面塔下；挥剑 3 次（前倾脉冲），每挥一下塔 shake + 血条 -7；血量每过 20 掉一层 3D 方块（碎砖粒子带重力反弹）。
- **推平**：塔整体倾倒 + 碎块飞散 → 胜利浮层。
- **兜底**：无 WebGL / 资源缺失自动退回 2D SVG 战场（原实现保留在 `#battle2d`），回归测试走兜底路径。
- 动画时序（走 1.7s + 3×450ms 砍）在 2D/3D 两路共享，保证测过的判定节奏不变。
