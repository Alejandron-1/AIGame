# 16 · 抓娃娃大赛 · 看图列式 开发文档 V1.0

> 素材来源：课堂实录截图 ×5（希沃白板课件「抓娃娃大赛」，2026-10-20）
> 知识点：一年级上册 **10 以内加减法 · 看图列式**
> 定位：多人竞赛练习器。现在课本上的加减法是「看图列式」——加减法不再只是抽象算式，
> 而是用**图的记号**来表达：**大括号=合并求总数（加法）**；**斜线划去 / 虚线方框=去掉（减法）**。
> 本游戏把这套图题语言做成可玩、可比赛的形式。

---

## 1. 核心教学表达（本游戏的心脏，必须严格还原）

六种图题，对应设置面板的六个勾选项。前四种为**基本题型**（默认全开），后两种为**进阶题型**（默认关闭）。

| # | 图题类型 | 图的记号（截图实证） | 算式模板 | 例 |
|---|---|---|---|---|
| ① | **合并求总数**（加法） | 左右**两组**同类物体，下方**大括号**把两组括在一起，括号下标「**?个 / ?只**」 | `□ + □ = □` | 3 个梨 + 5 个梨，大括号 ?个 → 3+5=8（截图：4+3=7 兔子） |
| ② | **斜线划去**（减法） | 一排物体中**划掉几个**（每个上画一条斜线），下方「**还剩?只 / ?条**」 | `□ - □ = □` | 7 条鱼划走 4 条 → 7-4=3（截图实证） |
| ③ | **虚线框去掉**（减法） | 一排物体中**几个被虚线方框框住**（表示拿走），下方「还剩?只 / ?条」 | `□ - □ = □` | 5 只小鸟框走 2 只 → 5-2=3（截图实证） |
| ④ | **求另一部分**（减法） | 全部物体画在一起，**大括号下标总数**（如「9个」「4串」），右侧标「**?个 / ?串**」问另一部分 | `□ - □ = □` | 9 个苹果括号标 9个，已知一部分 8 → 9-8=1（截图实证）；4 串葡萄括号标 4串，已知 1 串 → 4-1=3 |
| ⑤ | **连加 · 三部分**（进阶） | **三组**物体，大括号括全部，下标「?个」 | `□ + □ + □ = □` | 2+3+4=9 |
| ⑥ | **连减 · 划去+框走**（进阶） | 同一排里**先划去几个、再虚线框走几个**，下标「还剩?」 | `□ - □ - □ = □` | 9-2-3=4 |

**图题规范（拍板）**：
- 物体用大号 emoji 呈现（Bird/Cat/鱼/虎/苹果/梨/葡萄/兔子/蝴蝶…池子 ≥10 种），每题一种物体。
- 划线记号：从物体左上到右下的一条深色斜线（截图样式）；虚线框：圆角虚线方框围住被拿走的几个。
- 大括号：横置 `{` 旋转为下括号（⏜形），括住的宽度 = 两组物体总宽，下方居中文字「?个 / 还剩?只」。
- **记号与算式一一对应**：括号→`+`；斜线/虚线框→`-`；问号所在位置 = 等号右边待填槽（求另一部分时问号在图侧）。
- 数量约束（10 以内）：①  两部分各 1~9 且和 ≤10；②③ 总数 2~10、去掉 1~(总数-1)；④ 总数 3~10、已知部分 1~(总数-1)；⑤ 三部分各 1~9 且和 ≤10（默认不出，勾选才出）；⑥ 同理。


- **算式槽样式**：圆角白底方块；**当前待填槽带玩家色描边**（红/黄/蓝/紫光标），填入后描边消失；
  已填槽显示数字，等号后最后填答案槽。
- **数字键盘**：三行 `1 2 3 4` / `5 6 7 8` / `9 0 + -`，白色圆角按键；
  最底行左侧「退格」、右侧玩家色大按钮「确定」。
- 加减键只在对应模板的运算符槽可用（模板已定符号时加减键置灰，防误触）。

## 4. 交互流程

1. **开局**：设置弹窗确认 → 每列随机生成一道题（题型在勾选池中轮转，四个人的题互不相同）→ 倒计时开始。
2. **答题**（四人同时、互不等待）：
   - 当前槽有玩家色描边，点数字键盘填入 → 自动跳到下一槽；运算符槽已由模板定死不可改。
   - 「退格」回退上一槽；填错可反复改，**不惩罚**。
   - 点「确定」校验：
     - **答对** → 确定钮变「**答对啦！**」（玩家色）+ 欢快音效 → 本列上方**爪子下降抓住一个娃娃、升起、移到自己颜色的筐上方松爪掉入**（+1 分，分数徽章跳动）→ 2 秒后该列出新题。
     - **答错** → 算式槽抖动 + 爪子照样下抓，但**升到半空娃娃掉回娃娃堆**（不得分）+ 轻音效 → 不锁定，继续改答案再试。
3. **倒计时结束**：锁键盘 → 结算弹窗。
4. **结算（截图原样还原）**：大弹窗「比赛结束」，副标题「X号 获得第一！」；
   **领奖台**四阶（第一名金 1 / 第二名银 2 / 第三名铜 3 / 第四名），每阶上方显示玩家名、分数、
   头像（熊猫=冠军、小鸭=亚军，按名次分配）；底部三按钮「**再来一局**」（同设置重赛）/
   「**调整设置**」（回到设置弹窗）/「**查看赛场**」（关闭弹窗看娃娃机战利品，可再点结算）。

## 5. 拍板细节（截图未定义处）

1. **计分**：答对 1 题 = 1 分 = 抓 1 个娃娃；分数与筐中娃娃数一致（截图 3号 1分、筐里 1 个娃娃，实证）。
2. **出题公平**：每列独立题池轮转（四人题型尽量错开）；同一时刻四列题目两两不同。
3. **答错**：不扣分、不锁定、可无限重试（课堂原则：错误不惩罚）。
4. **多人同屏防误触**：300ms 防抖只作用于**同一列面板内的同一元素**；不同列/不同键的多点触控全部放行
   （四五个孩子同时点一块大屏，这是硬约束）。
5. **倒计时最后 10 秒**：计时器变红 + 滴答音，营造比赛气氛；归零锁操作。
6. **得分动效分级**：弱机（掉帧）自动减少彩带粒子，爪子动画保留（「自动适配」的实现口径）。
7. **不写 localStorage**：刷新即重置（课堂课件惯例）；但单次会话内「再来一局」保留学生名字与设置。
   → **V1.1 修正**：「数的范围」一项例外地持久化（`localStorage['zhuawa_settings']`，只存 `{max}`），
   老师按进度切到 5 以内后下次打开不用再点一遍；人数/时间/名字仍不持久化。
8. **教师快捷键**（隐藏）：`空格`=暂停/继续、`R`=整场重开、`Esc`=返回目录、`A`=自动填正确答案（调试用）。
9. **音效**：Web Audio 程序合成（按键嗒、答对叮咚、爪子机械音、掉落噗）；语音 TTS 报「X号 答对啦」
   （zh-CN，rate≈0.85），API 不可用静默降级。
10. **工程形态**：单文件 HTML 零依赖，双击即用；以 1920×1080 教室大屏为基准，
    用 vw/vh + clamp 做相对布局（沿用第 1 关修复结论：居中一律 `translate(-50%,-50%)`，禁止
    「百分比 top + 自身百分比 translate」混用）。

## 7. V1.1 迭代记录（教师验收后修改，2026-10-20）

| # | 教师原话 | 落地做法 |
|---|---|---|
| 1 | 「图案要待在各自位置的中间，不要往左右两边太过」 | 分组题 `.figline.grpline` 由 `justify-content:space-between` 改为 **grid 等分**（`grid-auto-columns:minmax(0,1fr)` + `justify-items:center`），每组固定在自己那一格的中心（2 组即 25% / 75%）；`.figbox` 加 `width:100%`，让大括号与 `?个` 跟整行对齐而不是跟最宽那组 |
| 2 | 「不同图案大小区别比较大，整体放大一点、统一大小」 | 用 canvas 采样每个 emoji 的墨迹面积（em²），按 `k = sqrt(0.60 / area)` 归一化（🍇 0.431 → k1.18，🦋 0.797 → k0.87），再整体 ×1.15；`margin:0 -0.12em` 吃掉 emoji 字形左右各约 0.19em 的空白，在同样宽度里多放大 15~20%；`@media (max-width:1700px)` 降到 1.04 防 1366 溢出 |
| 3 | 「还剩?个这些文字不用出现，跟课本保持一致」 | 删除全部「还剩?X」文字，只在物体下方画大括号、标 `?X`；题面提示语一律不做 |
| 4 | 「减法左右两边要挨近一点，加法左右才要分开」 | 加法保持两组等分（`.grpline`）；减法/虚线框/求另一部分加 `.gsub`（flex 居中、`column-gap:0.26×isz`）；**纯划线题直接合并成一整排**（前 free 个干净、后面带斜线），跟课本「一整排里划掉一部分」一致 |
| 5 | 「设置里可以设置计算的数的范围，比如只学到 5」 | 设置面板新增「数的范围」5~10 六个胶囊 → `S.settings.max`；出题器全部约束改用它（和/总数/连减次数都不超上限）；**键盘上超过范围的数字键置灰**（`.dis`），`pressKey` 顶部统一拦截，按了不落格；「教学范围」三条文案跟随（5以内综合/加法/减法）；持久化到 `localStorage['zhuawa_settings']`，脏值（<5、>10、坏 JSON）忽略 |
| 6 | 同步上线 | 注册进根 `index.html`（第 27 个游戏）+ `thumbs/zhuawa.png` 缩略图，推送 GitHub Pages |

**测试**：`test_zhuawa.js` 27941 条断言全绿（六题型 × 6 档范围的出题不变量、设置界面胶囊与文案、持久化与脏值、键盘置灰与越界拦截、图形排布结构）。
**截图参数**（仅供验收，不影响正常使用）：`?demo=1` 直接开赛、`?demo=1&fill=1` 填一半、`?max=5` 按 5 以内出题。
