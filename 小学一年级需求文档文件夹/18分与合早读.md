# 18 分与合 · 数学早读（数字变形闪卡）

来源：小红书「数学早读还可以这么玩」视频（橘老师，一年级上册分与合）的模仿改造。原视频用的是网传"数字变形"PNG 素材包，版权不明；本项目按项目惯例**手绘 SVG 全套 0~10 数字变形**（葫芦8 / 天鹅2 / 蜗牛6 / 长颈鹿1 / 竹子7 / 蝴蝶3 / 帆船4 / 青蛙5 / 气球9 / 甜甜圈0），风格贴近原视频：粗棕描边、腮红、圆润可爱。

## 教学目标

- 一年级上册分与合的早读/齐读巩固：读熟「几可以分成几和几」「几和几可以组成几」句式。
- 先问后答：卡片先出思考态（含"？/几"），全班齐答后点击揭晓。

## 玩法（课件型，非对抗）

- 整屏一张大卡片：舞台居中放数字变形 SVG，下方大字句式卡。
- 两种卡型（对应视频两种句式）：
  - 分成：问题态舞台只放总数（如葫芦8），句「8可以分成几和6」；揭晓后舞台换成两部分（天鹅2+蜗牛6），句「8可以分成2和6」。
  - 组成：问题态舞台放 ？气泡+已知部分，句「几和1可以组成8」；揭晓后放两个部分，句「7和1可以组成8」。
- 操作：点按舞台/空格/→ 揭晓→再按下一张；← 回上一张。语音领读（speechSynthesis 中文）在出卡和揭晓时各读一遍。
- 自动翻页可选：手动 / 3秒 / 5秒 / 8秒（先自动揭晓再翻页）。

## 设置（赛前界面）

- **最大数 2~10 可调**（核心需求：指定 8 就只出到 8）。默认 10。
- 出题类型：分与合混合 / 只练分成 / 只练组成。
- 卡片模式：思考题（带？）/ 纯齐读（直接全显示领读）。
- 设置存 localStorage（键 `fenhezaodu_settings`，只存 max/kind/mode/auto）。

## 出题规则

- total 从 2 递增到最大数（教学进度顺序），每个 total 内部打乱。
- 每组 (a,b) a≤b、a,b≥1（不出 0），a=b 只出一张变体；每个数对出「分成」「组成」各一张。
- 全程可 ← 回看，不重复出题直到整副读完（读完循环重洗）。
