一年级数学互动游戏：排队找第几 详细开发需求文档

## 一、项目概述

**项目名称：**排队找第几（基数序数专项练习小游戏）

**适用学段：**小学一年级上册数学

**知识点：**

- 基数含义：几个（表示数量、一群）
- 序数含义：第几（表示位置、单独一个）
- 左右方位辨别

**运行环境：**纯前端网页（HTML+CSS+JS），无需服务器、无需后台，本地直接打开，适配教学大屏、希沃白板、电脑、触屏操作。

**产品目标：**替代枯燥练习题，让学生通过点击排队人物，直观区分「几个 / 第几、左边数 / 右边数」，适合课堂热身、随堂练习、公开课互动。

## 二、整体页面 UI 布局（严格还原成品游戏）

页面分为五大固定区域：顶部标题区、功能按钮区、题干展示区、人物排队主交互区、模式切换与提示区。

### 1. 顶部区域

- 左上角：大标题 **排队找第几**
- 右上角两个功能按钮：        
  - 【重新出题】一键刷新全新题目、人物、方向、数字
  - 【试听声音】语音朗读当前完整题干

### 2. 中央题干显示区

居中大号文本框，自动随机生成标准数学题干，例如：

- 从左边数，请点出第3个小朋友。
- 从右边数，请依次点出前4个小朋友。

### 3. 方向提示区

- 画面左侧固定显示：**左边→**
- 画面右侧固定显示：**←右边**
- 用于帮助一年级学生明确数数方向，降低理解难度

### 4. 核心交互区：人物排队区域

- 默认生成一排 **5个卡通小朋友头像卡片**
- 每个卡片底部自带白色序号数字：1、2、3、4、5
- 头像样式可爱、统一、护眼，适合儿童
- 点击卡片反馈：轻微缩放动画 + 红色高亮边框 = 选中状态
- 可重复点击取消选中

### 5. 底部模式与提示区域

两个单选模式按钮（互斥切换）：

- 模式一：找“第几个”（序数模式）
- 模式二：找“几个”（基数模式）

最下方教学提示文字（自动跟随题目切换）：用于给学生做题引导。

## 三、两大核心游戏模式（完整规则）

### 模式一：找「第几个」——序数题型（只能选 1 个）

**题型规则：**

- 题干随机：从左边数第N个 / 从右边数第N个
- 学生 **只能选择一个人物**
- 选中正确位置 → 答对音效 + 答对提示
- 选错 → 答错提示、清空选择、可重新作答
- 再次点击其他头像自动替换选中对象，保证永远只有一个选中

### 模式二：找「几个」——基数题型（连续多选）

**题型规则：**

- 题干随机：从左边数前N个 / 从右边数前N个
- 要求学生 **按方向、连续点够对应人数**
- 必须连续、必须从起始第一位开始
- 点满指定数量后系统自动判题
- 全部连续正确 → 答对
- 不连续、跳着点、数量不对 → 直接判定错误

## 四、自动出题算法规则（重点）

无需人工题库，程序全自动随机出题：

每次点击【重新出题】，系统随机：

1. **随机模式**：序数题 / 基数题 二选一
2. **随机方向**：从左边数 / 从右边数 二选一
3. **随机数字**：根据总人数随机生成合法数字（不超范围）
4. **刷新人物**：重置所有选中状态、重置题号、重置提示语

**固定出题句式：**

- 序数：从左/右边数，请点出第N个小朋友。
- 基数：从左/右边数，请依次点出前N个小朋友。

## 五、交互反馈机制（全部细节）

- 头像点击：缩放动效 + 红框选中，二次点击取消
- 答对：欢快音效、弹窗/文字提示「答对啦！」
- 答错：低沉提示音、提示「再试一试」，清空选择
- 语音朗读：一键朗读整道题目，帮助识字少的一年级学生听懂题意
- 切换模式自动清空所有已选内容，防止残留

## 六、教学提示文案自动切换规则

\1. 序数题提示：看清数的方向，找准对应的第几个。

\2. 基数题提示：前几个表示连续的一共有几个，要按顺序数。

## 七、容错与边界逻辑（必须全部实现）

- 序数模式严格限制单选，禁止多选
- 基数模式必须连续，非连续直接判错
- 随机数字永远不会超出当前排队人数范围
- 重新出题强制清空所有状态，不会残留上次答案
- 适配触屏点击，按钮、头像点击区域足够大，适合小学生操作

## 八、视觉与风格规范

- 整体风格：清新浅蓝色教学风、护眼、简约、童趣
- 无多余花哨动画，不分散学生注意力
- 字体：黑体圆润大字，适合课堂远距离观看
- 配色：干净、明亮、低饱和度，符合电教课件标准

## 九、技术要求（给开发/AI 明确标准）

- 纯前端 HTML + CSS + JavaScript，零后端、零数据库
- 所有逻辑写死前端，打开即用，无需联网
- 代码结构清晰、中文注释完整
- 适配 16:9 教学大屏，布局居中自适应
- 支持鼠标 + 触屏双操作
- 刷新页面完全重置，无数据缓存

## 十、功能优先级（必做/可选）

### 必做功能（100%实现）

- 左右方向随机出题
- 基数、序数两种题型自动随机切换
- 单选/连续多选严格逻辑判定
- 答对答错音效与提示
- 语音读题、重新出题
- 完整UI界面与排队人物交互

### 可选扩展（本次不开发）

## 十一、游戏最终教学价值

彻底解决一年级学生最易错知识点：

分不清「几个和第几」、分不清「从左数从右数」

通过可视化排队人物，让抽象位置知识具象化，适合公开课、日常课堂互动使用。

## 十二、实现版说明（v1.1 优化记录，已实现）

1. **基数判题规则统一**：原文「跳着点直接判错」与「点满数量后判题」两种机制并存矛盾，实现统一为**顺序即时判定制**——每次点击必须是方向起点的下一个孩子（点对延续前缀、点击最后已选的可取消、点错立即温和判错并清空重选），点满 N 个即答对；另加"已点满忽略多余点击"防御
2. **序数判定修正**：答案为「从方向数第N个」对应的位置（从右数第N个 = 从左数第 6-N 个），验收阶段发现并修复了误判为「方向起点第1个」的严重 bug（150题×4路径压测全通过）
3. **模式按钮三态化**：初始双不选=两种题型混合随机；点选一个=锁定该模式；再点一次取消锁定回混合——解决「模式单选」与「重新出题随机模式」的冲突，UI 保持两个按钮不变
4. **答对后流程**：答对横幅变为可点击的「答对啦！👉 点这里下一题」，不弹窗打断课堂节奏
5. **方向提示强化**：起点侧方向牌黄色高亮+脉动动画（如"从右边数"时「←右边」发光）
6. **语音朗读**：采用浏览器自带 speechSynthesis（Windows 本地中文语音包，离线可用），语速放慢 0.85 倍
7. 头像为参数化内联 SVG（kidSVG 函数，5 种发型/配色），想换造型只需改一处
